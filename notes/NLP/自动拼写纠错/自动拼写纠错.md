# 自动拼写纠错

> 来源：吴恩达 NLP 课程 2 · Week 1 Assignment：Auto-correct
> 作业：`code/NLP_wuenda/lecture_two/first_week/homework/C2_W1_Assignment.ipynb`

## 1. 作业目标

实现一个简化的自动拼写纠错系统：

```text
语料库 → 统计词频和概率
错误单词 → 生成编辑候选
候选 → 词表过滤 → 概率排序 → 返回建议
```

![[自动纠错流程.svg|633]]

作业接收的是已经定位好的单词，例如 `dys`；它不负责从整句话中判断哪个单词错了。

## 2. 数据预处理

### 2.1 处理语料

`process_data(file_name)`：

1. 读取文本；
2. 转为小写；
3. 用正则表达式提取单词；
4. 返回单词列表。

```python
words = re.findall(r'\w+', text.lower())
```

返回列表是为了保留单词出现次数。

### 2.2 统计词频和概率

`get_count(word_l)` 返回：

```text
word_count_dict[word] = count(word)
```

`get_probs(word_count_dict)` 计算：

$$P(w)=\frac{count(w)}{\sum_{u\in V}count(u)}$$

作业使用 unigram 概率，只考虑单词本身的出现频率。

## 3. 四种字符串编辑

先把单词切成左右两部分：

```python
L, R = word[:i], word[i:]
```

例如 `cans`：

```text
('', 'cans'), ('c', 'ans'), ('ca', 'ns'), ('can', 's')
```

![[四种字符串编辑操作.svg|633]]

| 操作 | 含义 | 结果示例 |
|---|---|---|
| delete | 删除一个字符 | `cans → ans` |
| switch | 交换相邻字符 | `eta → tea` |
| replace | 替换一个字符 | `can → ban` |
| insert | 插入一个字符 | `at → bat` |

### 边界重点

- 删除、替换：通常遍历 `range(len(word))`；
- 插入：要遍历 `range(len(word) + 1)`，因为最后一个位置也能插入；
- 交换：要保证左右两部分都不为空，避免索引越界；
- 生成结果后用集合去重。

## 4. 生成纠错候选

### 4.1 一次编辑

```text
E1(word) = delete(word) ∪ switch(word)
           ∪ replace(word) ∪ insert(word)
```

`edit_one_letter()` 返回一次编辑得到的字符串集合。

### 4.2 两次编辑

对一次编辑结果再次做一次编辑：

$$E_2(word)=\bigcup_{u\in E_1(word)}E_1(u)$$

候选数量会快速增加，所以需要使用集合去重，并用词表过滤。

## 5. 自动纠错的核心流程

对输入单词 `word`：

```text
1. 生成 E1(word) 和 E2(word)
2. 保留出现在 vocab 中的候选
3. 查找每个候选词的概率 probs[word]
4. 按概率从高到低排序
5. 返回 top-n
```

候选可以表示为：

$$Candidates=\{word\}\cup E_1(word)\cup E_2(word)$$

有效候选为：

$$ValidCandidates=Candidates\cap vocab$$

例如：

```text
输入：dys
候选：days、dye、...
过滤：只保留词表中的 days、dye
排序：比较 P(days) 和 P(dye)
输出：概率更高的词排在前面
```

**关键区别：** 编辑操作负责生成候选，词表负责过滤，词频概率负责排序。最终不一定是编辑距离最短的词，而是在可接受候选中概率更高的词。

## 6. 最小编辑距离

### 6.1 定义

最小编辑距离表示：把 `source` 变成 `target` 所需的最小编辑代价。

本作业的动态规划只使用：

| 操作 | 默认代价 |
|---|---:|
| 插入 | 1 |
| 删除 | 1 |
| 替换 | 2 |

相同字符的替换代价为 0。

### 6.2 动态规划状态

$$D[i,j]=source[:i]\text{ 转换为 }target[:j]\text{ 的最小代价}$$

矩阵大小为：

```text
(len(source)+1) × (len(target)+1)
```

第一行表示从空字符串开始插入，第一列表示删除直到空字符串。

![[最小编辑距离动态规划.svg|633]]

### 6.3 状态转移

每个格子有三种来源：

```text
删除：D[i-1, j] + del_cost
插入：D[i, j-1] + ins_cost
匹配/替换：D[i-1, j-1] + r_cost
```

取三者最小值：

$$D[i,j]=min\begin{cases}
D[i-1,j]+del\_cost\\
D[i,j-1]+ins\_cost\\
D[i-1,j-1]+r\_cost
\end{cases}$$

其中：

$$r\_cost=\begin{cases}0,&source[i-1]=target[j-1]\\rep\_cost,&source[i-1]\ne target[j-1]\end{cases}$$

最终答案是右下角的 `D[len(source), len(target)]`。

## 7. 本章记忆

> 自动纠错 = 生成候选 + 词表过滤 + 概率排序。

> 字符串编辑包括删除、相邻交换、替换和插入；注意插入要遍历 `len(word)+1` 个位置。

> 最小编辑距离用动态规划计算，每个状态取删除、插入、匹配/替换三种代价的最小值。

这份作业把自动纠错拆成了“候选生成”和“候选选择”两步：编辑操作负责找到可能的词，词频概率负责判断哪个更常见。最小编辑距离则是用动态规划计算两个字符串之间到底差多少步。
