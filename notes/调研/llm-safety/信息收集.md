# 什么是大模型安全
1. 大模型安全就是让模型在面对正常请求时有用
2. 面对恶意输入时不被绕过，并且不生成有害或危险内容。

# 攻击vs防御
| 维度     | 攻击                      | 防御                      |
| ------ | ----------------------- | ----------------------- |
| 核心目标   | 找到模型的安全漏洞，让模型产生不该产生的内容  | 修补漏洞，让模型更难被绕过           |
| 典型问题   | 如何设计越狱 Prompt、恶意图像、对抗样本 | 如何检测恶意输入、控制生成、降低攻击成功率   |
| 研究过程   | 构造攻击方法 → 测试模型 → 提高攻击成功率 | 分析威胁 → 设计防御 → 测试防御是否有效  |
| 常见指标   | 攻击成功率、迁移性、隐蔽性、攻击成本      | 防御成功率、误拒答率、正常任务性能、推理开销  |
| 算力需求   | 通常较高，可能需要大量搜索、优化或多模型测试  | 从低到中等，轻量防御可以单卡完成        |
| 实验难度   | 攻击效果容易展示，但要做出新攻击通常竞争激烈  | 系统性要求更高，需要同时证明安全性和可用性   |
| 主要风险   | 只是在已有攻击上改动，创新不足         | 防御过强导致模型什么都拒答，或容易被新攻击绕过 |
