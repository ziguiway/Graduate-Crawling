# 什么是大模型安全
1. 大模型安全就是让模型在面对正常请求时有用
2. 面对恶意输入时不被绕过，并且不生成有害或危险内容。

# 攻击vs防御
| 维度       | 攻击                                      | 防御                                |
| -------- | --------------------------------------- | --------------------------------- |
| 核心目标     | 找到并利用模型漏洞                               | 降低模型被攻击后的风险                       |
| 当前技术成熟度  | 攻击工具链较成熟，GCG、PAIR、TAP、Crescendo 等已经形成体系 | 防御方法很多，但自适应攻击下经常失效                |
| 当前研究热点   | 自适应攻击、跨模态攻击、Agent 提示注入                  | 自适应攻击感知防御、视觉安全对齐、Agent 防御、评测方法    |
| 普通方向竞争   | **很高**                                  | **高**                             |
| 增量工作空间   | 较小，普通攻击变体容易被认为创新不足                      | 仍有空间，但普通 Prompt/Guardrail 防御也已经拥挤 |
| 真正有价值的空白 | 更强的自适应攻击、跨场景迁移                          | 防御鲁棒性、误拒答平衡、评测效度和行为级安全            |
| 算力需求     | 中高到高                                    | 低到中等，取决于是否训练                      |
| 对你的适配度   | 兴趣上可行，但算力和竞争压力大                         | 更适合，但必须避开普通防御套路                   |
