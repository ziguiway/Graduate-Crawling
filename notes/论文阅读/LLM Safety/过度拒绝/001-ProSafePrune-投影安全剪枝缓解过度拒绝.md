# ProSafePrune：Projected Safety Pruning for Mitigating Over-Refusal in LLMs

- 作者 / 年份 / 会议：Zijun Chen 等 / 2026 / ICLR 2026（依据所提供 PDF 首页标注，未联网核验）。

- 阅读依据：本地中文 PDF 正文及附录；页码均指 PDF 页码。以下区分作者主张、实验观察和阅读者判断。

- 飞书笔记：[ProSafePrune 阅读笔记](https://fcno2x2p9p0z.feishu.cn/docx/QLtld4Fyho05vrxRAXccaVyNnYg)（2026-11-01 经飞书 CLI 创建）。

## 一句话概括

> 用三类指令的激活构建子空间，通过一次性减去选定层权重中的低秩成分，缓解无害请求的过度拒绝；实验显示误拒明显减少，但真正有害请求的拒绝率仍有小幅下降。

## 摘要四要素

- **What（什么问题）**：模型错误拒绝含风险词汇、实际无害的请求，即过度拒绝；这类请求称为伪有害指令。
- **Why（为什么重要）**：单纯强化拒绝会损害实用性，直接移除拒绝方向又可能削弱真正的安全防护。
- **How（怎么做）**：用无害、有害、伪有害激活分别做截断 SVD；构造组合算子 Ω = (I − Πₛ)ΠᵤΠₚ；对选定中间层执行 W′ = W − λΩW。
- **So What（效果如何）**：LLaMA-2-7B 在 OR-Bench 上的合规率从 11.0% 升至 73.0%，PHTest 从 61.5% 升至 94.5%；AdvBench 安全得分从 100.0% 降至 98.5%，JailbreakBench 从 96.0% 降至 94.0%。修改完成后不增加推理阶段的编辑操作。

## 核心创新（1～3 点）

1. **机制解释**：作者提出“过度有害编码”假说：伪有害请求在内部激活中表现出偏强的有害信号。线性探针发现该信号与误拒相关，但尚不足以证明唯一根因。（第 3–4 页）
2. **三类子空间约束的低秩权重编辑**：同时使用无害、有害、伪有害子空间，避免无差别削弱有害表征。（第 4–5 页）
3. **离线修改与层选择**：先按表征可分性筛选中间层，再通过验证集搜索；结果合并到权重后即可正常推理。（第 5–6 页）

## 方法

- 输入：可访问权重和激活的白盒模型，以及三类指令，每类 200 条。
- 输出：经低秩权重编辑的模型；权重矩阵形状保持不变。
- 核心思路：削弱伪有害表征中与有害方向相关、且不能被无害子空间解释的成分。
- 关键模块：激活提取、token 均值池化、截断 SVD、组合投影、候选层验证、离线权重更新。
- 损失函数：权重编辑本身无需梯度训练，没有微调损失；用于分析的逻辑回归探针另行训练，不能据此把整个分析流程理解为完全没有训练。

### 从激活到三个投影矩阵

以下用一条 10-token 指令、输出维度 d = 4096、200 条指令、子空间秩 r = 16 举例。10 和 4096 是帮助理解的示例值，200 和 16 对应论文主要设置。

**第一步：记录某个线性子模块的输出。** 对第 t 个 token，输出 a_t = W h_t。这里是内部数值激活，不是最终回答；不应把它与整个 Transformer 层的输出混为一谈。

```text
token 1  → a_1：4096 个数
token 2  → a_2：4096 个数
...
token 10 → a_10：4096 个数

每条指令的激活形状：10 × 4096
```

**第二步：沿 token 维度平均。** 对应位置分别求平均，得到整条指令的一个摘要向量。

```text
平均向量 = (a_1 + a_2 + ... + a_10) / 10
10 × 4096 → 对 10 个 token 求平均 → 一个 4096 维向量

小例子：[1, 2, 3] 与 [3, 4, 5] 的平均为 [2, 3, 4]。
```

不同长度的指令都变成同维度向量，但均值池化也会丢失词序和局部差异。

**第三步：汇总同一类别的 200 条指令。** 以有害类为例，将每条指令的平均向量作为一列。

```text
A_u = [指令1的平均向量, ..., 指令200的平均向量]
A_u 的形状：4096 × 200
```

**第四步：截断 SVD。** 保留最主要的 16 个奇异方向。

```text
A_u ≈ U_u × Σ_u × V_uᵀ

U_u：4096 × 16，列是彼此正交的单位方向
Σ_u：16 × 16，记录对应奇异值
V_uᵀ：16 × 200，描述样本在这些方向上的组合
```

直觉：三维空间中的点如果集中在一张薄纸附近，用纸面上的两个方向就能近似描述它们。这里是用 16 个方向近似描述 4096 维空间中的样本。SVD 保证的是低秩重构误差最小，并不保证这些方向都是独有的“有害语义”；共同的语言和主题信息也可能被保留。论文按原始激活做 SVD，不能直接等同于对中心化数据做 PCA。

**第五步：构造投影矩阵。**

```text
Πᵤ = U_u × U_uᵀ
(4096 × 16) × (16 × 4096) = 4096 × 4096

对于 4096 维向量 v：
U_uᵀ × v → 16 个坐标
U_u × 这 16 个坐标 → 原空间中的 4096 维投影向量
```

另外两类数据独立重复同样步骤，得到 Πₛ = U_s U_sᵀ、Πₚ = U_p U_pᵀ。三个子空间可能重叠，而且每一层、每个子模块都计算自己的一套。

### Ω 公式的符号和执行顺序

```text
Ω = (I − Πₛ) × Πᵤ × Πₚ
```

| 符号 | 含义 |
| --- | --- |
| s / u / p | 无害 safe / 有害 unsafe / 伪有害 pseudo-harmful |
| U_s、U_u、U_p | 分别由三类激活的截断 SVD 得到的方向矩阵，形状 d × r |
| Πₛ、Πᵤ、Πₚ | 三类子空间的正交投影矩阵，形状 d × d |
| I | d × d 单位矩阵，Iv = v |
| I − Πₛ | 无害子空间的正交补投影，减去无害子空间中的分量 |
| Ω | 三个操作组合成的线性算子，形状 d × d |
| W | 子模块原权重，形状 d_out × d_in；此处 d = d_out |
| λ | 编辑强度，范围 [0, 1] |
| r | 子空间维度，主要设置为 16；更新矩阵的秩至多为 r |

矩阵乘法从右往左作用于列向量 v：

```text
v_1 = Πₚ v         ：先取伪有害子空间中的投影
v_2 = Πᵤ v_1       ：再取沿有害子空间的投影
v_3 = v_2 − Πₛ v_2 ：减去无害子空间中的投影
Ωv = v_3

W′ = W − λΩW
对于同一输入 h，若 v = Wh，则 W′h = v − λΩv。
```

**数学边界**：这些投影一般不可交换；Ω 通常既不对称，也不幂等，不能直接称为三个子空间交集的正交投影。最终 Ωv 一定与无害子空间正交，但不保证仍位于有害和伪有害子空间内。最终更新实际会作用于所有输入，并非仅对伪有害指令触发。

### 候选层选择

作者用 t-SNE 辅助观察三类激活，用轮廓系数量化可分性，在高分中间层附近筛选 5–10 个候选层，再用包含伪有害与有害指令的验证数据按 T.S. 搜索。（第 5–6 页）

## 框架图

```text
正常无害指令 → 模块激活 → token 均值池化 → SVD → U_s → Πₛ
真正有害指令 → 模块激活 → token 均值池化 → SVD → U_u → Πᵤ
伪有害指令   → 模块激活 → token 均值池化 → SVD → U_p → Πₚ
                              ↓
                    Ω = (I − Πₛ)ΠᵤΠₚ
                              ↓
             选择候选中间层，验证编辑层及强度
                              ↓
                      W′ = W − λΩW
                              ↓
                 保存修改后的权重，正常推理
```

原文方法公式与投影解释见 [[../../../../papers/llm-safety/过度拒绝/8194_ProSafePrune_Projected_Sa_zh-Hans.pdf#page=4|PDF 第 4–5 页]]。

## 实验设置

- 子空间数据：HEx-PHI、Alpaca-Cleaned、OR-Bench 各 200 条；OR-Bench 先经 GPT-4o 有害性评分，选中等评分指令。
- 过度拒绝评估：OR-Bench-Hard-1K 抽 200 条、PHTest 抽 200 条、XSTest 无害分支 250 条、OKTest 300 条。
- 安全评估：AdvBench 200 条、JailbreakBench 100 条。数据集名称本身不代表已验证所有攻击方式。
- 通用能力：MMLU 开发集 280 条、CommonsenseQA 200 条、GSM8K 200 条。
- Baseline：原始模型、SELF-CD、SCAN、SURGICAL。
- 模型：正文重点为 LLaMA-2-7B、LLaMA-2-13B、LLaMA-3-8B，附录扩展至 Qwen 等模型。
- 评价指标：C.R. 为无害请求合规率；S.S. 为有害请求拒绝率；WildGuard 判断拒绝和安全行为。T.S. 的定义与表中实现存在差异，见下文。
- 关键参数：主要秩 r = 16；LLaMA-2-7B 层区间 [13,16]、λ = 0.9；LLaMA-3-8B [19,22]、λ = 1.0；Qwen2.5-7B [16]、λ = 0.9。层编号沿用原文，复现前需核对代码索引。
- 解码：主要实验 do_sample = False；附录另对 LLaMA-2-7B 在温度 1 下做 3 次采样。
- 来源：第 6、17–18 页。尚未运行代码或复现实验。

## 实验结果

### 最重要的结果

LLaMA-2-7B，单位为百分比；前四项为 C.R.，后两项为 S.S.。（第 7 页表 1）

| 数据集 | 原模型 | ProSafePrune | 变化（百分点） |
| --- | --- | --- | --- |
| OR-Bench | 11.0 | 73.0 | +62.0 |
| PHTest | 61.5 | 94.5 | +33.0 |
| XSTest | 66.0 | 88.8 | +22.8 |
| OKTest | 58.3 | 81.7 | +23.4 |
| AdvBench | 100.0 | 98.5 | −1.5 |
| JailbreakBench | 96.0 | 94.0 | −2.0 |

OR-Bench 误拒率由 89.0% 降至 27.0%。不能把它误写成完全没有安全损失。

### 比 Baseline 好在哪里

LLaMA-2-7B 的四个无害基准平均 C.R. 为 84.5%，高于 SELF-CD 的 72.4%、SCAN 和 SURGICAL 的约 75.0%。但优势不适用于所有模型：Qwen2.5-7B 上，SCAN 的表列 T.S. 为 93.8，高于本文的 92.6；因此不能概括为所有模型都取得最佳权衡。

### 消融实验说明了什么

- 去掉 Πₚ：LLaMA-2-7B 的 OR-Bench 合规率从本文方法的 73.0% 升至 90.5%，但 AdvBench / JBB 安全得分降到 79.5% / 71.0%；说明伪有害子空间约束有助于限制安全损伤。（第 9 页表 3）
- 单模块：只编辑 V 时 OR-Bench 合规率为 30.5%，编辑整层为 73.0%；提示多个模块的作用可能相互关联。（第 8 页表 2）
- 层位置：中间层 OR-Bench 为 73.0%，底部、顶部编辑分别为 14.0%、13.0%；支持中间层选择。（第 22 页表 10）
- 编辑强度：λ 增大通常提高合规率，同时可能降低有害请求拒绝率，仍需要安全与实用性的权衡。（第 21 页）

### 通用能力与作者的结论

LLaMA-2-7B：MMLU 37.1 → 39.6，CommonsenseQA 49.0 → 53.0，GSM8K 23.0 → 25.5。作者认为这支持缓解对齐税；但 Qwen2.5-7B 的 MMLU 82.8 → 81.0、GSM8K 89.5 → 87.5，显示并非普遍提升。有限样本与缺少充分统计检验使这部分结论需要保留。（第 7–9、18 页）

## 与其他论文的关系

- **与 SELF-CD 的区别**：SELF-CD 在推理时比较带安全提示与不带安全提示的解码结果；本文提前编辑权重。
- **与 SCAN 的区别**：据本文相关工作，SCAN 用拒绝引导向量和自适应判别进行激活干预；本文用多维子空间构造固定权重更新。
- **与 SURGICAL 的区别**：据本文，SURGICAL 区分真实与虚假拒绝方向；本文用三类激活的子空间组合限制修改范围。
- **可以借鉴的点**：将“希望改变的行为”“要保留的能力”“二者混淆的输入”分别采样，用受约束的低秩更新减少副作用。上述比较依据本文，尚未独立阅读三篇原始工作。

## 论文存在的问题与下一步研究工作

### 论文存在的问题

1. **因果解释尚不充分**：线性探针读出有害性信号，不等于模型一定用该信号决定拒绝。干预改善行为支持假说，但尚未证明唯一根因。
2. **SVD 方向并不天然具有语义纯度**：最大化保留激活能量不等于最优区分安全与有害。类别、词汇、长度等混杂因素需要对照。

### 作者提出的未来工作

第 10 页局限性提出：扩展真实交互基准和领域专业、多轮场景；探索自适应剪枝，应对静态子空间无法适应安全概念及输入分布变化的问题。方法目前要求白盒访问，黑盒 API 场景适用性有限。


## 阅读疑问

- **Ω 各个符号是什么意思？** 见方法中的符号表；Π 是投影矩阵，U 是构成子空间的方向，r 和 λ 才是需要选择的超参数。
- **为什么 10 × 4096 会变成 4096？** 对 10 个 token 的向量逐位置取平均，没有把 4096 个特征也平均掉。
- **为什么要先 Πₚ，再 Πᵤ，最后 I − Πₛ？** 按作者意图，先限定伪有害相关表征，再提取有害相关分量，最后保护无害相关方向。改变顺序通常改变结果。
- **为什么不只减去有害方向？** 消融显示这样虽然更少拒绝，但真正有害请求的拒绝能力明显下降。
- **剪枝后模型是否更小、更快？** 矩阵尺寸不变，不等于稀疏化或模型压缩；部署优势是没有额外的逐次推理编辑操作。
- **仍待核对**：投影构建是否对激活中心化、padding 与特殊 token 如何处理、构建集去重、层区间索引、多个层的子空间是否顺序重算、T.S. 代码实现。论文概述不足以替代代码核查。

## 我的理解

这篇论文最值得学习的是“以正常无害、有害、容易误拒的无害数据共同约束低秩编辑”的方法路线。三个子空间不是三个预设标签区域，而是不同类别激活中提取的主要方向，因此既会重叠，也会包含共有信息。

Ω 可以当作连续筛选信号的线性算子来理解，但不能当作精确识别错误拒绝神经元的工具。W′ = W − λΩW 的作用是对固定输入的模块输出减去 λΩv；它会影响所有输入，是否保留真正的安全能力最终仍要由实验检验。

阅读结论：缓解过度拒绝的实验信号明确，离线部署方式实用；“认知偏差根源”和“降低对齐税”的强解释仍需要更多因果证据及更完整的评估。
