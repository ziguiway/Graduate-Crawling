# 编辑防御攻防研究 · 完整 idea（一步一步版）

> 本文是想法本身的最清晰版本：从立靶子到改进方案，一步一步，每步只说一件事。

## 第 1 步：靶子是什么

DELMAN（ACL 2025 Findings）和 EVA（期刊扩展版）用**模型编辑**做部署后安全防御：LLM 被越狱攻击后，直接改权重植入防御，0.4h 完成，推理零开销。EVA 把同一机制从文本扩到图像。

## 第 2 步：它们的机制

在 MLP（模型的 key-value 记忆库）里写一条联想：**有害词 → 拒绝方向**。

- **key（触发器）**：GPT-4 圈出有害词（bomb/hack）→ 每词生成 5 条**无害随机句**（"What is a bomb?"）→ 喂原模型取关键层激活、平均 → 指纹 k\*。原文自认 k\* 是 "context-insensitive"——**故意不看语境**，因为要"这个词出现在哪都触发"。
- **value（响应）**：训出拒绝方向 v\*，两项损失：有害 query 必须逼出拒绝句（L_safe）+ 良性问法输出分布不许动（**KL 损失**）。KL 校准用的良性句子**只有一种句式**（"What is a {token}?"）。

**防御逻辑一句话**：触发器无条件命中这个词，误触发全靠 KL 事后兜底。

## 第 3 步：这个设计的两颗雷

**雷一（攻击侧）**：触发器不分语境，所以**换词就能绕开**——同义词/谐音/拼音首字母/base64 让词的表示偏出 k\* 附近，触发器就哑了。EVA 测过的不知情 adaptive 攻击（只是重生成、攻击者不懂机制）就使 Vicuna ASR 0.068→0.112、Qwen2.5 0.012→0.113（近十倍）。**知情攻击能推到多少，无人知晓。**

**雷二（用户侧）**：KL 只见过一种良性句式，部署时面对所有句式（新闻/比喻/医学）——**校准范围外的误伤，是赌的，不是保证的**。而两篇论文**没有任何 over-refusal 测量**（全文检索确认，XSTest 连提都没提）——核心卖点"不误伤"从未被验收。


## 第 5 步：论文怎么组织（四环闭环）

1. **点火（攻击章）**：绕指纹词汇攻击 + 编辑对冲 + 抽词攻击，三线并行。
2. **归因（枢纽）**：每次成功绕过归入三类——**key 没命中 / value 推不动 / key 编辑错了位**（用激活距离 + activation patching 判）。这个诊断两篇论文都没做过，且归因结果直接决定改进往哪挖。
3. **验伤（审计章）**：给 DELMAN/EVA/LED/DINM 全家族做**首套统一误伤基准**——良性敏感 query **按语境分层**（新闻/比喻/医学/安全研究，分层依据就是 KL 的单句式校准）。独立于攻击结果成立。
4. **改设计（改进章）**：诊断指向病根（key 不看语境 + KL 只见过一种句式），对应改进见第 6、7 步。
5. **验收闭环**：改完的模型用攻击套件 + 误伤套件**反向重测**，三关全过才算成功：攻击挡得住、误伤不升、utility 不掉。

## 第 6 步：改进一（主贡献）——把触发器从"语境无关"改成"语境选择"

**原版**：k\* 是"这个词在所有语境下的公共成分"——一把万能钥匙，谁都开门，防误伤全押在门后推力校准（KL）上。

**我们的做法**：给每个有害词造**两把钥匙**——

1. **采样两组句子**：
   - 有害组：把词嵌进真实有害语境（HarmBench 原句及改写，现成）→ 取激活平均 → **k_H**（"这个词干坏事时的脸"）
   - 良性组：嵌进四类良性语境（新闻/比喻/医学/安全研究——**直接复用审计章的分层 query，一章数据喂另一章**）→ **k_B**（"它说正经事时的脸"）
2. **先验证可分性**（pilot 判决数）：算两簇距离比（d_between/d_within）+ 线性分类器，**按四类分别算**。EVA 的 PCA 已旁证有害 key 自聚成簇（信号存在），但"同一个词有害用法 vs 良性用法可不可分"无人测过。
   - 可分 → 改进成立，走第 3 小步；
   - 不可分 → 结论转为"词级编辑防御的设计上限"（论文照样成立，method 变 analysis）。**没有死局。**
3. **平移 key**：编辑用的 key 改为 **k_edit = k_H − α·(k_B − k\*)**——把 key 从共享位置**推离良性区**。
   - 有害语境的 bomb：激活靠近 k_edit → **触发拒绝** ✓
   - 良性语境的 bomb：激活离 k_edit 被主动拉大 → **根本不命中**（不是 KL 事后擦屁股，是门前就不开）

**这一步同时治两颗雷**：治雷二（良性不命中→误伤大降）；顺带收窄雷一（有害组采样含变体改写，最简单的同义替换攻击被顺带吃掉——写明是附带收益）。

**与 AlphaSteer 的区别**（审稿必问）：AlphaSteer（ICLR 2026）也防误伤，但机制是**抑制**——推理时外挂 steering 向量，命中后用零空间压到近零；我们是**选择**——离线改权重，从地址层面不命中，改完零开销。机制正交、应用层不同。

## 第 7 步：改进二——KL 的三步手术

KL 的病两条：**只见过一种句式**（校准窄）+ **编辑完就冻结**（校准死）。

1. **扩校准**：KL 的良性分布从单模板换成四类语境集合（复用 B 组数据，零成本）——v\* 被"四类都要中性"共同塑形。
2. **减负**：key 侧让大部分良性输入不命中——KL 的对手从无限集变成小长尾。不是 KL 变强，是它的任务变轻。
3. **可生长**（回应 DELMAN 自己的 limitation 3）：部署后定期跑轻量哨兵审计（每类 50 条）→ 某类过拒绝超阈值（5%）→ 补采该类句子、重新编辑（0.4h）→ **双验收**（误伤降了 + ASR 没回升），不过就回滚（权重快照）。把他们的"连续编辑案例研究"升级成**带触发、带回滚的运维协议**——用原作者承认的 limitation 做我们的贡献点。

**改进一和改进二是接力不是替代**：key 侧把打不了的区域（可分性差的类别）让出来，KL 侧在打得了的区域里把校准做满。若 key 侧某类失效，KL 侧的宽校准正好接住残余。

## 第 8 步：改进三（副消融）——良性 key 刹车

**解决什么**：给改进一的假设上保险。改进一依赖"可分性"假设，假设万一在某类不成立，误伤会漏出来——刹车把这些漏网的接住：**就算误触发，也白触发**。

**怎么做（四步）**：
1. 取改进一良性组句子的激活向量（每条句子一个）；
2. **聚类压缩**成少量锚点（如 200 个向量 → 3 个代表，写太多会伤 utility）；
3. 把刹车记录塞进**同一个最小二乘**一起解：良性锚点 → "输出跟原来一字不差"（value 取编辑前该位置本来的输出，约束是严格恒等——数学上最干净的"不动作"）；
4. 验证：误伤降多少 / ASR 没回升 / utility 没掉。

**为什么只当副消融、不当贡献**：它是**白名单**——只保护采样过的位置，没见过的新句式保不住（改进一的子空间有泛化能力，它没有）；且与改进一目标相同、数据相同，单独不构成贡献。它的价值 = 保险条款 + 审稿人问题"可分性不成立怎么办"的数据答案。

## 第 9 步：改进之间怎么互相验证（消融账本）

| 配置        | 语境选择 key              | 宽 KL | 刹车  | 回答的问题        |
| --------- | --------------------- | ---- | --- | ------------ |
| DELMAN 原版 | ✗                     | ✗    | ✗   | 基线           |
| 只宽 KL     | ✗                     | ✓    | ✗   | KL 手术单独多大效果  |
| 只语境选择     | ✓                     | ✗    | ✗   | key 手术单独多大效果 |
| 完整版       | ✓                     | ✓    | ✓   | 投稿配置         |
| + 对照      | 完整版上再加 AlphaSteer 式强化 |      |     | 两机制正交还是冗余    |

每行都过三关：攻击挡得住 / 误伤不升 / utility 不掉。

## 第 10 步：执行与出口

- **P0 两周 Pilot**（第一步先做）：复现 DELMAN + 造变体攻击集 + 量两个判决数（变体 ASR 恢复幅度 & 可分性比值）→ **Gate G0**：撑不起就止损，沉没成本 ≤ 2 周。
- 之后：P1 三线攻击（W3–8）→ P2 全家族分层审计（W9–12，**此时已可砍版投稿**）→ P3 改进+验收（W13–16）→ 写作投稿（2027-01）。
- **三个出口**：完整闭环论文（主）／砍版：攻击+审计+归因独立成文（兜底）／负结果短文（保险，需攻击全败且误伤≈0）。
- **没有"做砸"的分支**：可分性成立→方法论文；不成立→分析论文（设计上限）；攻击失败→稳健性审计（低一档）；误伤≈0→给 DELMAN 补正面证据。

## 附：本 idea 的三个诚实标注

1. 附带收益（变体覆盖）不冒充主贡献；
2. 刹车是保险不是方法，消融里如实报数；
3. 可分性不成立时整篇论文转向 analysis 体裁——这是设计好的退路，不是失败。
