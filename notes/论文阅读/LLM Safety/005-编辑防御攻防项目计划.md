# 编辑防御攻防研究 · 项目计划

![[计划流程图.svg]]

> 一句话版本：**用比作者更强的机制感知攻击击破 DELMAN/EVA 的防御，用从未被测过的过拒绝审计暴露其隐性代价，把两者的共同病根（key 语境无关）改成语境感知的 key，最后用攻击+误伤双套件反向验收——攻防闭环一篇论文。**

## 一、对象与已核实的弹药库

**靶子**：[[../../../papers/mllm-safety/DELMAN_2502.11647.pdf|DELMAN]]（ACL 2025 Findings）+ [[../../../papers/mllm-safety/EVA_2605.14750.pdf|EVA]]（期刊扩展版，仓库自标 IEEE TPAMI 2026）。
**机制**：MLP 里写死"有害词指纹 k*（中性句平均、故意语境无关）→ 拒绝 value"，KL 正则兜良性场景。
**两个赌注**（= 我们的两个攻击面）：① 有害 query 一定带着这些词；② KL 兜得住一切良性场景（**从未被独立测量**，两篇全文无 XSTest、无 over-refusal 指标）。

## 二、阶段计划（对照流程图）

### P0 · 两周 Pilot（W1–W2）—— 机制故事验证，不成立即止损

复现 DELMAN（Vicuna-7B + Llama2-7B）→ 造变体攻击集（同义/谐音/拼音首字母/base64）→ **同时量两个数**：ASR 恢复幅度、失效归因（被绕过样本在关键层激活到 k* 的距离分布；对失败样本做 activation patching 强制命中 k*，若恢复拒绝则 value 通路完好、问题在 key）。
**Gate G0**：pilot 数字撑得起第四/五章的机制故事吗？撑不起 → 出口 A（止损换题，沉没成本 ≤ 2 周）。

### P1 · 机制感知攻击（W3–W8）—— 三条武器线

- **A1 绕指纹**：同义词/谐音/拼音首字母/base64，让词表示偏出 k* 邻域。对照组就是 EVA 自己的不知情 adaptive（0.068→0.112、Qwen 0.012→0.113，相对近 10 倍）——知情攻击要比这更狠。
- **A2 编辑对冲**：JailbreakEdit（代码可用）在 k* 同位置写竞争联想；TME（白盒移除安全变换，ASR 84.86%）作机制参照。**DELMAN/EVA 均未引用 TME，这个引用空白是我们的安全牌。**
- **A3 抽词环节攻击**：DELMAN 防御管线依赖 GPT-4 抽词——防御的输入是另一个 LLM，诱导抽错/抽漏 → 编辑错 key。机制感知程度最高、无人做过。
- **归因枢纽**（两篇都没做）：失效时是 key 没命中 / value 推不动 / 抽词抽错？归因结果直接决定 P3 改进方向。

### P2 · 过拒绝审计（W9–W12）—— 独立于 P1 成立

- 对象：DELMAN / EVA / LED / DINM 编辑防御**全家族**（首套统一误伤基准）。
- 套件：XSTest + 良性敏感 query 按**语境分层**（新闻/比喻/医学/安全研究）——依据：KL 训练时良性句子只有 "What is a {token}?" 单一句式（公式 4），部署时面对全部句式，所以按句式分层测。
- VLM 侧：新闻图片（灾害/武器/医疗）天然"良性但敏感"，接上 [[004-EVA Editing for Versatile Alignment against Jailbreaks]] 的多模态线。
- **定位差异**：vs When LLM Defenses Backfire（2607.24392）——他们审通用防御 trade-off，我们审编辑家族 + 机制级语境分层。

### P3 · 改进：语境感知 key（W13–W16）—— 第六章收缩版

- **主贡献（唯一）**：双语境采样造 key——有害语境 + 良性语境各采一组，两组指纹可分 → 触发器看语境行事。依据：EVA 的 PCA 分析已显示有害 key 自聚成簇（可分性信号存在，pilot 再坐实）。
- 副消融：良性 key 刹车（良性指纹映射到"不动作"value）。
- **已让出的**（related work 而非贡献）：AlphaSteer（2506.07022，ICLR 2026，零空间保 utility）、NullSteer（2603.22094，VLM 零空间 steering）、AlphaEdit 零空间线。这些挤掉了原第六章的方向二、三。
- 同一套双语境数据同时喂主贡献和副消融，不另花时间。

### 验收闭环

用 P1 攻击套件 + P2 误伤套件**反测改进后的模型**，三项全过：① 攻击挡得住（ASR 不回升）② 误伤不升（分层过拒绝率不涨）③ utility 不掉（MT-Bench / MM-Vet-v2 持平）。
