## 一、这个故事

### 主角：一条写进权重的"联想"

DELMAN 的全部魔法就是一条联想：**看到有害词 → 拒绝**。它分两半。

"看到"这一半叫 key。作者给 GPT-4 一个 prompt，让它对每个有害词生成 5 条随机句子（附录 C.2 的原文要求是 "generate random sequences... avoid harmful content"）——这些句子本身无害，只是碰巧含这个词，论文里引的例子就是 "What is a bomb?"。把 5 条句子喂给原模型，取这个词位置在关键层的 MLP 中间态，平均一下，得到指纹 k\*。论文 4.4 节自己写明：这保证了 k\* 是 "robust, **context-insensitive** representations of harmful semantics"——**故意造得跟语境无关**。

"拒绝"这一半叫 value。v\* 是训出来的，目标函数有两项：有害 query 必须逼出拒绝句（L_safe）；良性问法 "What is a bomb?" 的输出分布必须不许动（KL，公式 4 原文就是这么写的）。

所以整个防御的逻辑是：**key 无条件命中这个词，KL 来擦屁股**——凡是 "bomb" 出现的地方 key 都会触发，全靠 KL 把良性场景的输出按住不动。EVA 把同一套机制从文本扩到了图像（用跨模态注意力给图像 token 也找指纹），骨架没变。

### 埋着的引线：两个软肋，加第三条线

"key 不看语境、全靠 KL 兜底"这个组合，天然有两个软肋，一个站攻击者视角，一个站正常用户视角。

**软肋一（攻击侧）：绕开指纹。**既然触发条件是"这个词的向量落在 k\* 附近"，攻击者只要让词的表示偏移出去就行——同义词、谐音、拼音首字母、base64、表情符号。这跟 EVA 测过的 adaptive attack 有本质区别：EVA 只是把 GCG/AutoDAN 在编辑后的模型上**不知情地**重新生成一遍（原文 "regenerate adversarial test cases directly on each edited LLM"），攻击者并不知道防御原理。我说的攻击是攻击者**读过论文、冲着机制本身来的**。而且 EVA Table 6 里已经有个不祥的预兆：仅仅不知情的重新生成，Vicuna 的 ASR 就从 0.068 涨到 0.112、Qwen2.5 从 0.012 涨到 0.113（相对近 10 倍）。知情攻击能推到多少，没人知道。

**软肋二（用户侧）：KL 到底兜不兜得住，没人验收过。**注意 KL 的训练目标里，良性句子只有一种模板——"What is a {harmful token}?"（公式 4）。可 "bomb" 能出现在无数种良性语境里：新闻标题里、比喻里（"这节目是个 bomb，炸翻了全场"）、医学语境里。训练时 KL 只保护了一种句式，部署时要面对所有句式——**KL 只在见过的那一种良性分布上被校准过**。更关键的是：我全文检索确认，两篇论文没有任何 over-refusal 指标，XSTest 连提都没提。"不误伤"这个核心卖点，从头到尾没被独立测量过。

**第三条线：编辑打编辑。**你笔记 [[001-Injecting Universal Jailbreak Backdoors into LLMs in Minutes]] 的 JailbreakEdit 用同一套 MEMIT 骨架、反方向写一条"接受短语"后门：防御在 k\* 附近写拒绝联想，攻击在同位置写竞争联想。两篇互不引用、互不测对方，这个对局是空白。而且这一条线现在弹药更足了（这两篇是我后来逐个核实过的）：JailbreakEdit 的代码已确认可用（github.com/JohnnyChanV/JailbreakEdit，非空、含 easyeditor），拿来就能跑；另有一篇 TME（arXiv 2412.08201，"Model-Editing-Based Jailbreak"，白盒编辑直接移除安全关键变换，ASR 84.86%）——**DELMAN 和 EVA 都没引用它**，这个引用空白既是攻击武器的来源，也是我们论文的安全牌（说明"编辑防御 vs 编辑攻击"这个对局确实没人打过）。

### 把三条线拧成一篇论文

这三条线不是三个点子，而是同一根引线上的三段——先点火，再看伤在哪，最后改设计。落到论文就是三章。

**点火章（机制感知攻击）**：一组"绕指纹"的词汇攻击（同义/编码/谐音），一个 JailbreakEdit 对冲实验，再加一类没人做过的攻击——DELMAN 的防御管线依赖 GPT-4 抽词，**防御的输入是另一个 LLM**，那这个抽词环节本身就是攻击面：诱导它抽错、抽漏，防御就会编辑到错误的 key。同时做失效机理拆解：防御被绕过时，到底是 key 没命中（指纹偏移了），还是 key 命中了但 value 推不动？这个诊断两篇论文都没做过，而它直接决定改进往哪挖——key 没命中，就往"让指纹覆盖变体词"方向改；value 推不动，就往"强化 value 锚点"方向改。

**验伤章（过拒绝审计）**：拿 XSTest 和一批良性敏感 query（新闻/比喻/医学/安全研究语境）去测，量出两篇论文从未报告的数字：这套"号称不误伤"的防御到底冤枉多少正常人，并且**按语境类型分层**报告——因为 KL 只在单一句式上校准过，分层一测就知道它兜的是哪几种。如果 KL 真的兜得住，这是给 DELMAN 补上有价值的证据；如果兜不住，"key 无条件命中 + KL 兜底"这个设计就要重审。

**改设计章（语境感知 key）**：攻击和误伤的机理诊断共同指向同一个改法——把 key 从"语境无关"改成"语境感知"。不再用中性句平均，而是同时采有害语境和良性语境两组句子，故意把两种指纹都测出来，利用"有害语境的 k 和良性语境的 k 可分"这个性质让触发器看语境行事（EVA 自己的 PCA 分析已经显示有害 key 自聚成簇，说明可分信号存在）。再配一个副消融：把良性语境的 key 也显式写进去、映射到"不动作"的 value，等于给触发器加个刹车。这里要诚实让地盘：核实发现 AlphaSteer（arXiv 2506.07022，ICLR 2026）和 NullSteer（arXiv 2603.22094，VLM 版零空间 steering）已经把"零空间约束保良性"这条路占了——所以原设想的第三个方向（AlphaEdit 式零空间）撤出贡献列表，降为 related work 里的已有工具。

**闭环逻辑**：点火章证明"现设计会破"→ 改进的动机；验伤章证明"现设计有隐性代价"→ 补充动机；归因诊断告诉你改进该往哪挖；改进做完，用前两章的攻击套件和误伤套件**反向验收**。一环扣一环，这才是一篇完整的攻防论文，而不是点子拼盘。

## 二、这个计划怎么落地（对照图从上往下读）

### P0 · 两周 Pilot（W1–W2）——先花两周买一个"要不要继续"的答案

复现 DELMAN（Vicuna-7B + Llama2-7B，编辑一次 0.4h，服务器现成）；同时把变体攻击集造出来（同义/谐音/拼音首字母/base64）。然后**一次实验量两个数**：ASR 恢复了多少（验攻击侧故事），以及失效归因——对被绕过的样本，看它在关键层的激活离 k\* 有多远；再做 activation patching，强行把激活拉回 k\*，如果拒绝恢复了，说明 value 通路完好、问题出在 key（验机理故事）。两个数一出来，第四、五章的机制故事是真是假立刻见分晓。

**Gate G0（图里的紫色菱形）**：数字撑得起故事就往下走；撑不起就走出口 A 止损换题——沉没成本封顶两周，这是整个计划最贵的保险。

### P1 · 机制感知攻击（W3–W8）——三条武器线

A1 绕指纹（词汇变体，对照基准就是 EVA 自己那组不知情 adaptive 的数字）；A2 编辑对冲（JailbreakEdit 代码直接用，TME 当机制参照，在 k\* 同位置写竞争联想）；A3 抽词环节攻击（构造对抗 query 诱导 GPT-4 抽错词——机制感知程度最高、目前完全无人做的一类）。三线并行，产出汇进**归因枢纽**：每一次成功绕过都标记为 key-miss / value-fail / wrong-key 三类之一，这个分类法本身就是论文的贡献之一，而且 LED/DINM/EVA 全家族通用。

### P2 · 过拒绝审计（W9–W12）——独立成立，不依赖 P1 的成败

对象是 DELMAN/EVA/LED/DINM **整个编辑防御家族**（此前没有任何工作给这个家族做过统一误伤基准）；套件是 XSTest + 按语境分层的良性敏感 query；VLM 侧用新闻图片（灾害/武器/医疗画面）天然"良性但敏感"的场景，正好接上 EVA 的多模态线和 fake-news 方向的积累。定位上要跟近邻工作划清界线：When LLM Defenses Backfire（arXiv 2607.24392）审的是通用防御的 trade-off，我们审的是**编辑家族 + 机制级语境分层**——不重叠。注意：网传有一篇 NeurIPS 2024 的 over-refusal 审计，我没核实到它存在（搜索给的 arXiv 号对应一篇石墨烯物理论文），related work 不引用它，投稿前再扫一轮。

### P3 · 语境感知 key（W13–W16）——收缩后的第六章

主贡献只有一条：双语境采样造 key（前面故事里讲的改法）。副消融：良性 key 刹车。两者共用同一套双语境数据，不另花时间。AlphaSteer/NullSteer/AlphaEdit 进 related work，不进贡献。

### 验收闭环

改完的模型必须过三关：① P1 的攻击套件打不动它（ASR 不回升）；② P2 的误伤套件测不出新增误伤（分层过拒绝率不涨）；③ utility 不掉（MT-Bench / MM-Vet-v2 持平原模型）。这一步就是图里从右侧绕回攻击套件的那条回环线。

## 三、三个出口（这棵树没有"做砸"的分支）

**出口 B（主指望）**：攻击成功 + 归因清晰 + 改进有效，完整闭环论文，主打稳健性，目标安全四大或 NLP 主会，周期 4–5 个月。**出口 C（兜底）**：P3 滑期也不要紧，P1+P2+归因本身就独立成文——W12 结束就到达可投稿状态，周期 2.5–3 个月。**出口 D（保险）**：只有攻击全败且误伤恰为零才走到这——用超作者强度的独立审计加"它为什么稳"的机理解释，转 workshop 或二档短文；小概率事件，买保险用的。

## 四、时间轴（2026-10-09 启动）

W1–2 Pilot（10 月中，Gate G0）→ W3–8 攻击三线（10 月底–11 月，M1 武器库成型）→ W9–12 审计（12 月上–中，**M2 砍版可投**）→ W13–16 改进+验收（12 月下–1 月上，M3 闭环）→ W17 起写作（2027-01，M4 投稿）。
