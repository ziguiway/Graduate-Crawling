### 必须修正的前提（影响 007 步骤 2 与 008 对照设计）

**EVA 的 key 构造已不是"无害随机句平均"。** EVA 全文（IEEE TPAMI 2026）Eq.9：key 是对**含该词的 N 条多样化有害 query 变体**取 gate⊙up 激活平均。即 EVA 的 k\* 已约等于 008 里的 k_H——"有害语境采样"这一半**对 EVA 不构成增量**（只对 DELMAN 构成）。改进一的真实增量收窄为三件套：**同词双语境对比采样（k_B）→ 可分性判决 → 平移公式 k_edit**。另外 EVA 无 XSTest/Or-Bench 测量（007 的"误伤从未被验收"指控对 EVA 仍成立）；其 Sec V-F "contextual synergy" 研究编辑语料丰富度，写宽 KL 前先核对它变的轴。

### 必引与划界清单

- **C-ΔΘ**（arXiv 2602.04521，2026-02）：同目标（离线编辑选择性拒绝、低误伤），机制不同族（EAP-IG 电路定位 + 受限权重算术），未碰 DELMAN 家族。
- **SAME**（ACL 2026）：恶意↔良性配对表征学 safety direction + 双零空间投影（知识+安全保留侧），但它是给知识编辑做安全加固（防 ASR 上升），非防御编辑，且**自己不测 over-refusal**。
- **TripWire**（arXiv 2608.14392）：安全神经元钳制；对 DELMAN 的批评原文可引："有害语义分布式存在，靠有害词表定位 + 逐通路压制 → 大干预 footprint + 每个被压神经元都是潜在效用损失"。
- **DMM-Gov**（arXiv 2509.18868）：编辑运维治理骨架（准入→灰度→监控→回滚→证书），**零实验立场论文**，且 refusal rate 在它那里是"该拒的拒对了没"（构念相反）、编辑验收无 ASR、无 over-refusal 哨兵、无量化批量预算——运维协议有 8 处空白可主张。
- **JPU**（arXiv 2601.03005）：on-policy 攻击缓冲 + 路径矫正，打的是遗忘不是编辑防御；其"缓冲→约束重编辑"循环可镜像。
- **EvalSafetyGap**（arXiv 2606.30219）：呼吁防御评测必须报 over-refusal + 攻击适应状态——递刀，写 motivation 用。
- DualEdit（ICLR 2026）的 "value anchoring"（K-means 聚类成锚点）是刹车手法的已发表先例——刹车降为消融是对的。

## 二、XSTest 实验结果定位（2026-10-20 前后完成）

DELMAN 批量编辑（200 条 HarmBench，Qwen2.5-7B）在 XSTest：**过拒 2.4–3.2% → 28.8%（官方 judge 全拒）/ 16.8%（人工严格下界）**，四口径一致 17–36%；unsafe 侧 67.5%→78% 无漏防。**双机制**：key 命中组全拒 46.2% vs 未命中组 15.9%（后者仍为基线 5.7 倍）；同形词场景 13/25 失守；误拒弥散分布。

方法论过硬（四口径交叉 + 人工复核 + 官方协议复判 + 命中/未命中分层——分层设计无先例）。缺一块：**剂量响应**（25/50/100/200 条编辑 vs 过拒率），最便宜的下一实验，同时喂 §3 审计和运维协议的批量预算数值。

文献佐证：SAME 测到纯良性知识批量编辑（500→2500 条）使 ASR 12.3%→17.9%（累积 rank-1 污染的直接证据）；TripWire Table 1 里 DELMAN 过拒仅 3.8–15%（MT-Bench 口径、非批量）——说明批量累积是放大器。

### 把 ~30% 拆成三个可攻击分量

| 分量 | 证据 | 代数根源 |
|---|---|---|
| A. key 命中误拒 | 命中组 46.2%；同形词大面积失守 | k\* 语境无关词锚，良性用法激活落在 k\* 附近 |
| B. 全局污染底数 | 未命中组 15.9%（5.7×），弥散 | Δ = Rk\*ᵀ/k\*ᵀk\* 对一切与 k\* 有内积的激活漂移，200 次累加无全局约束 |
| C. value 方向"响" | 串扰、编造断言 | v\* 含拒绝方向分量，残差扰动被放大成拒绝 |

KL 的病根：逐条局部软约束，200 个编辑各自只见过一种句式，无任何机制保证全体良性流形不动。

## 四、六套方案

- **方案 A · 良性零空间联合最小二乘**（打 B，主升级）：K₀ = 同批有害词的四类良性语境激活（复用审计章数据）+ 通用良性锚点（Alpaca + 86 条人工复核误拒样本）→ SVD 得 P → 200 键联合解 `ΔW = R·K₁ᵀP·(K_pK_pᵀP + K₁K₁ᵀP + λI)⁻¹`；单 key 简化 `ΔW = R(Pk*)ᵀ/(k*ᵀPk*+λ)`。保证：对一切 x ∈ span(K₀)，(W+ΔW)x = Wx 严格成立（任意 λ）。
  **关键链接：008 闸 1 的可分性比值与 α_P ≜ k\*ᵀPk\* 是同一件事的两种语言**——α_P 是"有害特异分量里未被良性子空间吸收的部分"；可分性高 → α_P 大 → 编辑精确达成（残差 α_P/(α_P+λ)）；α_P→0 → 数学上不存在既改 k\* 又不动良性的线性映射 → 007 的"设计上限"分析分支。P0 判决数直接用 α_P。
- **方案 B · 语境选择 key**（打 A）：007 改进一原样保留；可加 TripWire 漏斗（硬负例 + FDR）作零成本变体。
- **方案 C · 对比恒等行**（打 A+边界）：原改进三刹车升级为目标函数里的恒等约束行（含词良性 query → 原输出），并入联合 LS。
- **方案 D · 批量合并替代顺序累加**（打 B 工程根源）：三档——①200 键联合闭式解（天级）；②TripWire 认证支撑（≤0.3% 参数）；③C-ΔΘ Alg2 逐神经元合并。剂量响应实验归入此方案。
- **方案 E · 过拒缓冲迭代矫正**（JPU 镜像，兜底）：挖当前模型误拒样本（Parents 留、恢复的弃）→ 变异扩覆盖 → 受限矫正闭式更新（只碰已编辑支撑 + 恒等/效用锚行 + 少量有害锚行）→ 复检双门。静态一次性正则不够（JPU 实证），必须 on-policy。
- **方案 F · 安全特化运维协议**（治理面）：分批编辑 + 分层哨兵 + "拒答率跳升→回滚"触发器 + 双验收门（OR↓ 且 ASR 不↑）+ 同管线分阶段再编辑；29% 事故即 motivating incident。

### 与 007 计划的映射

| 007 组件 | 处置 |
|---|---|
| 改进一（语境选择 key） | **保留为主贡献**（= 方案 B） |
| 改进二 KL 扩校准 | **降级为软正则组件**：A 接管硬保证，宽 KL 只兜 span 外残余，消融单独报数 |
| 改进二-3 可生长协议 | **升级为方案 F** |
| 改进三 刹车 | **被 A+C 吸收**：降为联合 LS 的恒等行/投影消融 |

## 五、论文故事与章节结构
