## 项目一句话

用比作者更强的**机制感知攻击**击破 DELMAN/EVA 的编辑防御，用从未被测过的**过拒绝审计**暴露其隐性代价，把共同病根（key 语境无关）改成语境感知 key，攻击+误伤双套件反向验收——攻防闭环一篇论文。

## 一、本次会话已完成的工作

1. **精读两篇 PDF 并核对了原文细节**（不是只靠笔记）：
   - DELMAN key 的构造：GPT-4 生成 5 条**随机中性句**（附录 C.2 prompt 原文 "avoid harmful content"），取关键层 MLP 中间态平均 → k\* 是故意**语境无关**的（4.4 节 "robust, context-insensitive representations of harmful semantics"）。
   - value 优化：L_safe + KL，其中 **KL 的良性句只有一种模板 "What is a {harmful token}?"（公式 4）**——这是第五章分层审计的立论根基。
   - EVA 的 adaptive attack（Table 6）是**不知情重生成**（原文 "regenerate adversarial test cases directly on each edited LLM... hyperparameter settings kept identical"）：Vicuna 0.068→0.112、Qwen2.5 0.012→0.113、Mistral 0.122 vs 0.863 vanilla、Llama2/Llama3.1 几乎不涨（0.000/0.005）。**知情（机制感知）攻击没人测过。**
   - 两篇全文均无 over-refusal 指标、无 XSTest（全文检索确认）。
   - DELMAN 三条官方 limitation：只测 7B~14B 通用模型、依赖 GPT-4 抽词、连续编辑只初步验证。EVA 结论亲自点名 future work：**Video-LLM** 和更轻量的参数定位。
   - DELMAN 连续编辑只有 4 轮 case study（4.5 节，Llama2-GCG）；EVA 声称支持 sequential updates 但**无专门实验**。

## 三、关键实验设计备忘（写论文时直接用）

- **攻击的对照基准**：EVA 自己的不知情 adaptive 数字（上表），我们的知情攻击必须显著超过它才有说服力
- **归因三分类**：key-miss（激活偏出 k\* 邻域）/ value-fail（命中但推不动）/ wrong-key（A3 抽词攻击导致编辑错位）——这个分类法对 LED/DINM/EVA 全家族通用，本身是论文贡献
- **P2 分层审计的立论**：KL 只在 "What is a {token}?" 单一句式上校准（公式 4），部署面对所有句式 → 按新闻/比喻/医学/安全研究分层测过拒绝率
- **VLM 侧 P2 素材**：新闻图片（灾害/武器/医疗）天然"良性但敏感"，接 fake-news 方向积累
- **负结果出口 D 的三条件**（若攻击全败）：攻击强度超作者 → 回答"为什么稳"（机理）→ 定位 workshop/二档；且 B 线独立出数，不存在全盘死局
