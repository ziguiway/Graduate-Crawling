# 循环神经网络（Recurrent Neural Network, RNN）

> 李宏毅《深度学习教程》第 5 章笔记。
> 核心问题：输入有顺序时，模型怎样把前面读到的信息带到后面？
> 关联笔记：[[自注意力机制|第 6 章 自注意力]]、[[Transformer|第 7 章 Transformer]]、[[notes/NLP/n-gram语言模型/n-gram语言模型|n-gram 语言模型]]。

---

## 0. 为什么需要 RNN？

前馈网络只看当前输入。可是在序列里，**相同的词放在不同上下文中，答案可能不同**：

```text
抵达 上海  → 上海是“目的地”
离开 上海  → 上海是“出发地”
```

只把“上海”输入前馈网络，两次输出必然一样；但正确标签取决于前面的“抵达”或“离开”。所以模型需要一份会随阅读过程更新的**记忆**。RNN 就是在普通网络中加入这份记忆。

词本身需要先变成向量。教材从 **one-hot** 讲起：词表中每个词占一个维度，当前词的位置为 1、其他为 0。它能标识词，却不表达词义，词表外词还得归入 `other`；实际模型通常再通过 embedding 把词变成可学习的稠密向量。

## 1. RNN：把前文压进隐状态

RNN 在第 $t$ 步同时读取当前输入 $x_t$ 和上一时刻的隐状态 $h_{t-1}$：

$$
h_t = \phi(W_xx_t + W_hh_{t-1}+b_h), \qquad y_t = \mathrm{softmax}(W_yh_t+b_y)
$$

- $x_t$：当前读到的词、声音帧等；
- $h_t$：截至当前为止，模型对前文的压缩记忆；
- $y_t$：当前输出，例如“这个词属于哪个槽”的概率；
- $W_x, W_h, W_y$：**所有时间步共享同一组参数**。

![](assets/循环神经网络/rnn-unrolled.svg)

这张图里沿时间展开的是**同一个 RNN**，不是三个不同网络。正因为 $h_t$ 会传到下一步：

1. 同一个词在不同上下文中可以有不同输出；
2. 输入顺序交换后，状态演化不同，结果也会不同；
3. RNN 能处理变长序列，但必须一个时间步接一个时间步算，不能像 Transformer 那样整句并行。

### 1.1 常见变形

| 模型 | 它额外做了什么 | 适合什么情况 |
| --- | --- | --- |
| 深层 RNN | 每个时间步堆多层循环层 | 表示更复杂的模式 |
| Elman / SRN | 把隐藏状态 $h_{t-1}$ 传回去 | 最基础、最常说的 RNN |
| Jordan | 把输出 $y_{t-1}$ 传回去 | 用任务输出作为反馈 |
| Bi-RNN | 同时从左到右、从右到左读 | 标注任务可利用完整句子的左右文 |

Bi-RNN 在预测当前位置时能看到整句，但不能用于严格的实时输出，也不能在生成任务中提前看未来答案。

## 2. LSTM：让模型自己决定“记、忘、说”

简单 RNN 的隐状态每一步都会被新计算结果覆盖。序列一长，早期信息容易被冲淡。**LSTM（Long Short-Term Memory）**把内部记忆记作 $c_t$，并用三道门控制信息流：

![](assets/循环神经网络/lstm-gates.svg)

| 门 | 它回答的问题 | 数学作用 |
| --- | --- | --- |
| 输入门 $i_t$ | 当前信息要不要写入？ | 控制候选记忆 $\tilde c_t$ |
| 遗忘门 $f_t$ | 旧记忆还留多少？ | 控制 $c_{t-1}$ |
| 输出门 $o_t$ | 当前记忆要露出多少？ | 控制输出 $h_t$ |

核心更新是：

$$
c_t = \underbrace{f_t\odot c_{t-1}}_{\text{留下旧记忆}} + \underbrace{i_t\odot\tilde c_t}_{\text{写入新记忆}},
\qquad h_t=o_t\odot\tanh(c_t)
$$

门的值经 sigmoid 后在 0 到 1 之间：接近 0 相当于关，接近 1 相当于开。教材中的“输入门、遗忘门、输出门”就是这三件事：**写什么、留什么、什么时候读出来**。

> [!tip] 最关键的差别
> 简单 RNN 是“新状态覆盖旧状态”；LSTM 是“旧记忆保留一部分，再加上新记忆”。只要遗忘门接近 1，早期信息就有一条较平坦的加法路径往后传。

### 2.1 GRU

GRU 是 LSTM 的简化版，门更少、参数更少，性能常接近 LSTM。教材用“旧的不去，新的不来”概括它：写入新信息时，会联动清理相应旧信息。LSTM 过拟合或模型太重时，可以尝试 GRU。

## 3. RNN 怎样学习：BPTT 与梯度问题

槽填充中，每个位置都有标签，整句话的损失是各时间步交叉熵之和：

$$
L=\sum_{t=1}^{T}\operatorname{CE}(y_t,r_t)
$$

训练时不能把词打散，因为“上海”的输出依赖前面“抵达”产生的状态。把 RNN 沿时间展开后，再从后往前传梯度，叫做**随时间反向传播（Backpropagation Through Time, BPTT）**。

```text
前向：x1 → h1 → h2 → ... → hT → L
反向：L  → hT → h(T-1) → ... → h1
```

同一个循环权重会在很多时间步里反复相乘，因而带来两类问题：

| 现象 | 为什么 | 常用处理 |
| --- | --- | --- |
| 梯度消失 | 连乘后越来越小，早期信息收不到学习信号 | LSTM / GRU、合适初始化 |
| 梯度爆炸 | 连乘后越来越大，更新会剧烈震荡 | 梯度裁剪（clipping） |

梯度裁剪是给梯度设上限，避免一次更新“飞出悬崖”。LSTM 主要缓解梯度消失，**不能自动消除梯度爆炸**，所以实践中仍常配合裁剪。

## 4. RNN 能做什么？

教材把应用按输入输出的形状分成三类：

| 类型 | 形式 | 例子 | 核心想法 |
| --- | --- | --- | --- |
| 多对多，等长 | $x_1...x_T \to y_1...y_T$ | 槽填充、词性标注 | 每个位置给一个标签 |
| 多对一 | $x_1...x_T \to y$ | 情感分析 | 用最终状态概括整段文字 |
| 多对多，非等长 | 声音帧 $\to$ 字符 | 语音识别 | 输入与输出不必一一对应 |

### 4.1 CTC：不知道对齐时怎么办？

语音每 0.01 秒一帧，帧数通常远大于字符数，也不知道每个字对应哪几帧。CTC 给输出加一个 blank / `null`：

```text
好 null null 棒 null 棒 null  →  删除 null  →  好棒棒
```

这样能区分“好棒”和“好棒棒”。训练时只需要整段音频和完整文字，不必逐帧标注；CTC 会把所有合法对齐的可能性汇总起来学习。

### 4.2 Seq2Seq：输入和输出长度都不固定

RNN 可以先读完整个输入，把最终状态作为摘要；再从 `<BOS>` 开始，一个 token 一个 token 地生成，直到 `<EOS>`：

```text
输入序列 → 编码 RNN → 最终状态
                         ↓
<BOS> → 解码 RNN → 第一个词 → 作为下一步输入 → ... → <EOS>
```

这可以做机器翻译、直接语音翻译和句法解析。但“把整句压进一个最终状态”会成为长句的信息瓶颈，所以第 6、7 章用 [[自注意力机制|注意力]] 和 [[Transformer]] 让模型能直接参考输入序列的多个位置。

## 5. RNN 到 Transformer：同一个问题的不同答案

| 模型 | 如何使用过去信息 | 代价 / 局限 |
| --- | --- | --- |
| n-gram | 显式看固定长度窗口 | 看不到更远上下文、数据稀疏 |
| RNN | 逐步压缩到 $h_t$ | 远处信息易忘、时间步串行 |
| LSTM / GRU | 门控地维护记忆 $c_t$ | 仍是串行计算 |
| 自注意力 | 当前词直接找相关的历史位置 | 计算量随序列长度增长快 |

第 6 章中，自注意力让当前位置直接关注远处位置，不必要求信息一路藏在 RNN 的状态里；同时它能并行计算，这也是 Transformer 后来广泛替代 RNN 的重要原因。

---

## 6. 一句话记忆

> RNN 用隐状态把前文带到下一步；LSTM 用门控决定记什么、忘什么、什么时候输出，缓解长距离信息在普通 RNN 中容易丢失的问题。

## 7. 我的理解 / 个人思考

我现在把 RNN 理解成“**持续更新的阅读笔记**”：每读一个词，模型都把当前词和已有笔记合成一份新的笔记，再带去读下一个词。它能理解顺序，是因为这份笔记的更新顺序不可交换；它又会忘，是因为无论多长的前文，最后都要塞进固定大小的状态。

LSTM 的价值在于把“更新笔记”细分成了三个决定：新信息是否写进来、旧信息留下多少、现在是否需要说出来。它没有让模型记住一切，而是让“保留和遗忘”变成可学习的选择。

顺着课程看，n-gram、RNN、LSTM、Transformer 都是在回答同一个问题：**当前输出应该依据哪些历史信息？** 差别只在于，n-gram 看固定窗口，RNN 把历史压进状态，LSTM 更会管理状态，而注意力可以直接回头找相关位置。
