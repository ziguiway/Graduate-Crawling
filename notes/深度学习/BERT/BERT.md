## 1. 为什么 BERT 难以从头训练？

BERT 的预训练任务可以理解为：把句子中的一部分词遮住，让模型根据上下文完成填空。预训练好的模型再用于下游任务时，通常只需要在普通 GPU 上微调约半小时到一小时；但从头训练一个 BERT，计算量会大很多。

以 ALBERT-base 为例：

- 预训练数据可以达到数十亿规模，但大多是从网络爬取的未标注文本。
- 预训练步数约为 100 万步，也就是参数要更新约 100 万次。
- 使用 TPU 也可能需要运行约 8 天；使用普通 GPU 可能至少需要约 200 天。

因此，实际使用时通常直接加载公开的预训练模型，再针对具体任务微调。自己训练 BERT 的研究价值不在于重复得到一个差不多的模型，而在于回答两个问题：

1. 能不能减少预训练所需要的计算资源？
2. 能不能通过观察训练过程，理解 BERT 是怎样逐渐学会填动词、名词和代词的？

论文 *Pretrained Language Model Embryology: The Birth of ALBERT* 就是从训练过程出发，观察模型能力如何形成，从而思考更高效的训练方式。

> 重要区分：**微调 BERT** 是在已有表示上学习一个具体任务，成本相对低；**预训练 BERT** 是从海量文本中学会语言规律，成本非常高。

## 2. Seq2Seq 模型如何做预训练？

BERT 主要是一个预训练编码器，适合抽取输入序列的表示。但翻译、摘要和生成等任务需要完整的 Seq2Seq 模型：编码器读取输入，解码器生成输出，并通过 cross-attention 使用编码器的信息。

### 2.1 去噪式 Seq2Seq 预训练

基本做法是先把原句损坏，再让模型还原原句：

```text
原始句子 x
    ↓ 施加扰动 / 损坏
损坏后的句子 x'
    ↓ 编码器 + cross-attention + 解码器
还原句子 x
```

编码器看到的是损坏后的输入，解码器的目标是输出未损坏的原句。这相当于直接预训练一个 Seq2Seq 模型，而不是只预训练编码器。

常见的损坏方式包括：

| 损坏方式 | 直觉 |
|---|---|
| 掩盖部分词汇 | 类似 BERT 的 Masked Language Modeling |
| 删除词汇 | 要求模型根据上下文补回缺失内容 |
| 打乱词序 | 要求模型恢复句子的结构 |
| 旋转词序 | 打破原始顺序后再恢复 |
| 掩盖与删除组合 | 同时增加局部缺失和结构扰动 |

### 2.2 MASS、BART 与 T5

- **MASS**：*Masked Sequence to Sequence Pre-training for Language Generation*。采用类似 BERT 的掩码方式，训练 Seq2Seq 模型还原句子。
- **BART**：*Denoising Sequence-to-Sequence Pre-training for Natural Language Generation, Translation, and Comprehension*。组合使用多种句子损坏方式，实验结果优于只采用单一掩码方式的 MASS。
- **T5**：*Exploring the Limits of Transfer Learning with a Unified Text-to-Text Transformer*。系统比较不同预训练目标和数据处理方式，把各种任务统一表示成“文本到文本”的问题。

T5 使用了 C4（Colossal Clean Crawled Corpus）数据集。这个数据集原始规模约 7 TB，即使下载完成也会带来存储压力；使用单个 GPU 进行预处理，按论文相关说明可能需要数百天。由此可以感受到，预训练的瓶颈不只是模型结构，也包括数据收集、清洗、存储和预处理。

## 3. BERT 为什么有用？

### 3.1 词嵌入不再只是固定向量

把文字输入 BERT 后，每个 token 都会得到一个向量。这个向量可以看作该 token 在当前句子中的语义表示。

相似含义的 token，其向量往往更接近。例如：

- “果”和“草”都可以表示植物，向量可能比较接近；
- “鸟”和“鱼”都属于动物，向量可能比较接近；
- “电”与前两类的关系较远，向量可能也更远。

更重要的是，BERT 输出的是**依赖上下文的向量**。同一个“果”在“吃苹果”和“苹果发布新 iPhone”中，向量不会完全相同：前者更接近食物或植物相关词，后者更接近电子产品或公司相关词。

这类表示称为**语境化词嵌入（contextualized word embedding）**。

### 3.2 如何观察语境化表示？

可以收集很多包含“果”的句子，把它们输入 BERT，取出每个句子中“果”的向量，再两两计算余弦相似度：

```text
“今天买了苹果吃”       → “果”的向量 v1
“喝苹果汁”             → “果”的向量 v2
“苹果即将发布新 iPhone” → “果”的向量 v3
“苹果公司的股价上涨”   → “果”的向量 v4
```

如果模型学到了上下文，前两类表示应该分别聚在一起，而“食物/水果”和“公司/电子产品”两类之间的相似度较低。把所有两两相似度组成矩阵，就能直观看到这种聚类结构。

### 3.3 BERT 与 CBOW 的关系

语言学家 John Rupert Firth 提出过分布式语义的思想：**一个词的意义取决于它经常出现的上下文**。例如，“果”经常和“吃、树”一起出现时，可能是水果；经常和“电、专利、股价”一起出现时，可能指苹果公司。

BERT 做填空时，会利用被遮住词两侧的上下文来预测它。中间 token 对上下文信息的压缩表示，就可以帮助分类器判断被遮住的词是什么。

这和更早的 **CBOW（Continuous Bag Of Words，连续词袋）** 很像：把中间词挖空，根据上下文预测它。CBOW 也能学习词向量，但它通常是浅层、线性的模型；BERT 可以看作更深、更强、且能够根据上下文改变表示的 CBOW。

CBOW 当年选择较简单的线性结构，主要受到当时计算能力和训练大模型成本的限制，并不是说更深的模型在理论上不能使用。

| 模型 | 表示特点 | 模型深度 |
|---|---|---|
| CBOW | 通常为词汇学习一个相对固定的向量 | 浅层、线性 |
| BERT | 同一个 token 根据上下文产生不同向量 | 深层 Transformer 编码器 |

## 4. BERT 能迁移到非语言数据吗？

一个有意思的实验是把 DNA、蛋白质或音乐当成“序列”处理：

- DNA 的基本符号是 A、G、T、C；
- 蛋白质由氨基酸序列组成；
- 音乐可以表示成音符序列。

以 DNA 分类为例，先把 A、G、T、C 映射成任意 token，再把序列输入 BERT，使用 `[CLS]` 的输出向量接一个随机初始化的线性分类器：

```text
DNA: A G A C
  ↓ 任意 token 映射
序列: we she we he
  ↓ BERT
[CLS] 向量
  ↓ 线性层
DNA 类别（EI / IE / N）
```

映射到哪些英文单词并不重要，关键是保留序列中的符号关系。实验结果表明，BERT 预训练模型可以帮助这类序列分类任务取得较好效果。

但这也提出了一个重要问题：如果输入本身不是人类语言，BERT 的效果就不能简单解释成“它理解了句子语义”。一种可能的解释是，预训练得到的参数本身就是一组适合优化大型模型的初始化参数。也就是说，BERT 的成功可能同时来自语义表示能力和良好的参数初始化，二者需要进一步实验区分。

> 迁移学习中的“预训练学到了什么”不能只看下游准确率，还要问：迁移的是语义、结构，还是一组有利于继续训练的参数？

## 5. 多语言 BERT

### 5.1 跨语言迁移

多语言 BERT 使用中文、英文、德文、法文等多种语言进行掩码填空预训练。Google 发布的版本使用了 104 种语言。

它的一个重要现象是：即使只使用英文问答数据进行微调，也可以迁移到中文问答任务。这种设置没有使用中英互译数据，也没有直接用中文问答训练集微调。

教材中的结果如下：

| 模型 | 预训练语言 | 微调语言 | 测试语言 | EM | F1 |
|---|---|---|---|---:|---:|
| QANet | 无 | 中文 | 中文 | 66.1 | 78.1 |
| BERT | 中文 | 中文 | 中文 | 82.0 | 89.1 |
| BERT | 104 种语言 | 中文 | 中文 | 81.2 | 88.7 |
| BERT | 104 种语言 | 英文 | 中文 | 63.3 | 78.8 |
| BERT | 104 种语言 | 中文 + 英文 | 中文 | 82.6 | 90.1 |

一个直观解释是：不同语言中表达相同含义的 token，经过多语言 BERT 后可能被映射到相近的位置。例如“兔子”和 `rabbit`、“跳”和 `jump` 的向量可能比较接近。这样，在英文任务中学到的问答能力就有机会迁移到中文。

### 5.2 用 MRR 衡量跨语言对齐

可以使用 **平均倒数排名（Mean Reciprocal Ranking，MRR）** 衡量不同语言的语义对齐程度：

$$
\mathrm{MRR} = \frac{1}{N}\sum_{i=1}^{N}\frac{1}{\mathrm{rank}_i}
$$

其中，`rank_i` 是正确跨语言对应词在候选结果中的排名。MRR 越高，表示相同含义但属于不同语言的 token 越容易互相找到，也就是跨语言嵌入对齐越好。

数据量是对齐效果的关键：每种语言只有约 20 万句时，模型效果不好；增加到约 100 万句后，跨语言对齐明显改善。很多跨语言能力只有在数据规模足够时才会出现。

### 5.3 多语言 BERT 同时保留“意义”和“语言”

多语言 BERT 并没有把不同语言完全混成一种语言。它可以把意思相同的词拉近，同时仍然保留语言身份信息：给它英文句子时，它通常用英文填空；给它中文句子时，它通常用中文填空。

语言信息可以从嵌入中找到。一种观察方法是：

1. 收集大量英文 token 的嵌入并求平均；
2. 收集大量中文 token 的嵌入并求平均；
3. 两个平均向量相减，得到一个近似的“语言方向”；
4. 给英文句子的嵌入加上这个方向，模型就可能把它看成更接近中文的表示。

在这个方向上，多语言 BERT 甚至可以进行一定程度的**无监督 token 级翻译**：把英文句子的表示移动到中文方向，再让模型完成填空，输出中文 token。但这种翻译质量有限，因为表面上相同含义的表示被拉近了，语言信息仍然隐藏在模型内部，并没有被完全消除。

## 6. 关键概念速查

| 概念 | 一句话理解 |
|---|---|
| 预训练 | 在海量未标注数据上先学通用表示 |
| 微调 | 用较少的标注数据适配具体任务 |
| 语境化词嵌入 | 同一个 token 因上下文不同而得到不同向量 |
| CBOW | 根据上下文预测被挖空的词 |
| MASS | 用掩码进行 Seq2Seq 预训练 |
| BART | 用多种噪声损坏句子，再进行去噪还原 |
| T5 | 把各种 NLP 任务统一成文本到文本 |
| MRR | 衡量正确跨语言对应项排名的指标，越高越好 |
| 跨语言对齐 | 不同语言中含义相同的 token 在向量空间接近 |

---

## 7. 一句话记忆

> BERT 通过上下文填空学到语境化表示；MASS、BART、T5 把这种思想扩展到 Seq2Seq；多语言 BERT 则进一步把不同语言的相同含义对齐，同时保留语言身份信息。

## 8. 我的理解 / 个人思考

- BERT 的核心价值不是“记住了很多词”，而是通过填空任务被迫学习“一个词应该怎样结合上下文来解释”。
- 预训练模型的能力来源不能只用“理解语义”解释。DNA、蛋白质和音乐的实验提醒我：好的初始化、序列结构建模能力和语义表示可能是不同因素。
- BERT 是编码器，擅长理解和表示；BART、T5 等去噪式 Seq2Seq 预训练则把能力延伸到生成任务。之后复习 [[Transformer]] 时，需要把编码器的双向理解和解码器的自回归生成放在一起比较。
- 多语言迁移很像在向量空间里学习“共享语义空间”，但语言方向仍然存在。因此“不同语言表示接近”不等于“语言差异已经消失”。
- 后续想补的问题：BERT 的 Masked Language Modeling 和 CBOW 在目标函数、上下文范围、参数共享方式上究竟有哪些严格差异？ALBERT 的参数共享和因子分解具体怎样降低了训练成本？
