## Q1：什么是主成分分析？notebook 里的代码到底在干什么？

### 问题描述

看 `NLP_C1_W3_lecture_nb_03.ipynb` 的时候完全懵了——什么旋转矩阵、协方差、特征值，一行代码都看不懂。到底什么是主成分分析？这个 notebook 在讲什么事？

### 回答

**PCA 的本质就是旋转坐标系，让数据在新方向上"散得最开"（方差最大）。**

notebook 用三个递进的例子讲这件事：

**例子 1：y = x（完全相关）**

```python
x = np.random.uniform(1, 2, 1000)
y = x.copy() * 1  # y = x，完全相关
```

数据全落在 45° 斜线上。PCA 对它做变换：

```python
pca = PCA(n_components=2)
pcaTr = pca.fit(data)
rotatedData = pcaTr.transform(data)
```

结果：
```
Eigenvectors（旋转矩阵）:
[[ 0.7071  0.7071]     # PC1 方向 = [cos45°, sin45°]
 [-0.7071  0.7071]]    # PC2 方向，垂直于 PC1

Eigenvalues（解释方差）:
[0.1667  0]            # PC1 占全部方差，PC2 = 0
```

**为什么是 0.7071？** `cos(45°) = sin(45°) = 0.7071`，数据沿 45° 分布，PCA 自动找到了这个角度。

**方差 0.1667 从哪来？** 均匀分布 `U(1,2)` 的方差 = `(2-1)²/12 = 0.0833`。x 和 y 各贡献 0.0833，合计 0.1667，全被 PC1 吃掉。

**例子 2：相关正态变量**

先用旋转矩阵制造相关数据，再用 PCA 还原：

```python
# 造两个独立正态变量
x = np.random.normal(0, 1, 1000)       # std=1
y = np.random.normal(0, 0.333, 1000)   # std=0.333

# ★ 用旋转矩阵混合成相关数据
angle = np.arctan(1 / 1)  # 45°
rotationMatrix = [[cos(angle), sin(angle)],
                   [-sin(angle), cos(angle)]]
data = np.dot(xy, rotationMatrix)  # 旋转 → 变相关

# PCA 还原
pcaTr = pca.fit(data)
# PCA 的旋转矩阵 = 原始旋转矩阵的逆 → 把数据"转回去了"
# 解释方差 ≈ [1, 0.111] = [std1², std2²]
```

**这就是 PCA 的核心**：它是旋转矩阵的逆向工程——找到把相关数据"打散"成不相关变量的那个旋转。

**例子 3：降维**

只保留 PC1，把 2D 压成 1D。方差大的轴信息多→保留，方差小的轴信息少→丢弃。

### 一句话记忆

> PCA 就是旋转坐标系找方差最大的方向（PC1），垂直方向是 PC2。方差大的保留信息多，方差小的可以丢掉实现降维。本质是对协方差矩阵做特征值分解，特征向量就是旋转矩阵。

## Q2：PCA 为什么能选出两个特征来画图？选出的那两个到底是什么？

### 问题描述

看 PCA 把 300 维词向量降到 2 维画散点图，不理解：它是怎么从 300 个特征里"选"出 2 个的？选出来的这两个到底代表什么？PCA 这个操作到底有什么用？

### 回答

**关键澄清：PCA 不是从 300 个特征里"挑" 2 个，而是把 300 个特征按权重"揉"成 2 个全新的数字。**

PC1 和 PC2 的本质是**所有原始特征的加权求和**：

$$\text{PC1} = w_1 \cdot f_1 + w_2 \cdot f_2 + w_3 \cdot f_3 + \dots + w_{300} \cdot f_{300}$$

$$\text{PC2} = v_1 \cdot f_1 + v_2 \cdot f_2 + v_3 \cdot f_3 + \dots + v_{300} \cdot f_{300}$$

每个词都做这个计算：
1. 把 300 个数字按 PC1 的权重加起来 → 得到 x 坐标
2. 把 300 个数字按 PC2 的权重加起来 → 得到 y 坐标
3. 这两个数就是它在散点图上的位置

**为什么是两个？** 因为目的是画图给人眼看，人眼只能看 2 维。`PCA(n_components=2)` 指定降到 2 维。想降到 3 维、10 维都行，但 3 维以上就画不了平面散点图了。

**PCA 怎么决定用哪些权重？** 目标是让数据在新轴上尽可能散开（方差最大）：
- 方差大 → 这个方向携带了最多信息 → 保留
- 方差小 → 信息少，很可能是噪声 → 可以丢掉

数学上，PCA 对**协方差矩阵**做特征值分解，最大的特征值对应的方向就是 PC1，第二大的是 PC2（且垂直于 PC1）。

**PCA 的三个用途：**

| 用途 | 说明 |
|---|---|
| 可视化 | 300 维词向量 → 2 维散点图，看词与词的语义关系 |
| 降维加速 | 高维 → 低维，减少计算量和内存 |
| 去噪 | 方差小的方向往往是噪声，丢掉反而更干净 |

### 一句话记忆

> PCA 不挑特征，而是把所有特征按权重揉成几个新的。权重的选择原则是让数据在新方向上尽可能散开（方差最大）。降到 2 维就能画图，降到更少维就能加速去噪。
