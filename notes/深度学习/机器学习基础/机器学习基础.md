## 0. 什么是机器学习？

机器学习就是**让机器具备找一个函数的能力**。函数太复杂、人类写不出来，就让机器自动找。

- 语音识别：输入声音信号 → 输出文字
- 图像识别：输入图片 → 输出图片内容
- AlphaGo：输入棋盘黑白子位置 → 输出下一步落子位置

## 1. 机器学习的三大任务类型

按"要找的函数输出是什么"分类：

| 任务 | 输出 | 例子 |
|---|---|---|
| **回归（Regression）** | 一个标量（数值） | 预测明天 PM2.5 的数值 |
| **分类（Classification）** | 从预设的选项中选一个 | 垃圾邮件检测（是/否）、AlphaGo（19×19 个落子位置中选一个） |

## 2. 机器学习找函数的 3 个步骤

以「视频点击次数预测」为例：输入是后台信息（订阅、点赞、观看次数），输出是隔天的总观看次数。

### 步骤 1：写出带未知参数的函数（模型）

$$y = b + w \cdot x_1$$

- $y$：要预测的值（今天的观看次数）
- $x_1$：已知信息（前一天的观看次数）——**特征（feature）**
- $b$、$w$：未知参数——$w$ 叫**权重（weight）**，$b$ 叫**偏置（bias）**

> 带有未知参数的函数叫**模型（model）**。
> 猜测来源于对问题本质的理解，叫**领域知识（domain knowledge）**——比如「今天的观看次数跟昨天有关」。

### 步骤 2：定义损失（Loss）

损失 $L(b, w)$ 是一个函数，输入是参数 $b$、$w$，输出代表「这一组参数有多不好」。

**计算过程**（以 $b=500, w=1$ 为例）：
1. 把 2017/01/01 的观看次数 $x_1=4800$ 代入 → $\hat{y}=5300$
2. 真实值 $y=4900$（真实值称为**标签 label**）
3. 计算误差 $e_1 = |y - \hat{y}| = 400$
4. 对 3 年所有训练数据重复，取平均：

$$L = \frac{1}{N} \sum_n e_n$$

**误差的几种计算方式：**

| 名称 | 公式 | 特点 |
|---|---|---|
| **MAE（平均绝对误差）** | $e = \|\hat{y} - y\|$ | 取绝对值 |
| **MSE（均方误差）** | $e = (\hat{y} - y)^2$ | 取平方 |
| **交叉熵（Cross Entropy）** | — | 当 $y$ 和 $\hat{y}$ 都是概率分布时使用 |

> $L$ 越大 → 参数越差；$L$ 越小 → 参数越好。

**误差表面（Error Surface）**：试不同的 $w$、$b$ 组合，画出损失的等高线图。越红损失越大，越蓝损失越小。

> ❓ Q：为什么损失可以是负的？
> A：损失是自己定义的，不一定是绝对值。比如设成「绝对值减 100」就可能为负。

### 步骤 3：解最优化问题（梯度下降）

找一个 $w^*, b^*$ 让损失最小：

$$w^*, b^* = \arg\min_{w, b} L(w, b)$$

**梯度下降（Gradient Descent）**步骤（先假设只有 $w$ 一个参数）：
1. 随机选初始点 $w_0$
2. 计算 $\frac{\partial L}{\partial w}\big|_{w=w_0}$（切线斜率）
3. 若斜率为负 → 左高右低 → 把 $w$ 变大；若斜率为正 → 把 $w$ 变小
4. 更新公式：

$$w^1 \leftarrow w^0 - \eta \cdot \frac{\partial L}{\partial w}\bigg|_{w=w^0}$$

**步伐大小由两件事决定：**
- 斜率大小（斜率大步伐大）
- **学习率（learning rate）$\eta$**——自己设定的，叫**超参数（hyperparameter）**

**什么时候停？**
- 设定的更新次数上限到了（次数上限也是超参数）
- 微分值 = 0（参数不再移动）

> ⚠️ 梯度下降的"局部最小值"问题：可能停在 local minima 而非 global minima。但作者强调——**局部最小值其实是个假问题**，真正的难题不在它。

**两个参数时**：分别算偏导数，同时更新。

$$w^1 \leftarrow w^0 - \eta \cdot \frac{\partial L}{\partial w}\bigg|_{w^0, b^0}, \quad b^1 \leftarrow b^0 - \eta \cdot \frac{\partial L}{\partial b}\bigg|_{w^0, b^0}$$

> 在 PyTorch 等框架中，微分是自动计算的（autograd）。

## 3. 线性模型（Linear Model）

只用 $y = b + w \cdot x_1$ 预测，得到的曲线就是真实曲线往右平移一天——因为只看前一天。

**真实数据有周期性**：每隔 7 天会有 2 天特别低（周五、周六）。→ 引入领域知识，改模型：

$$y = b + \sum_{j=1}^{7} w_j \cdot x_j$$

| 模型 | 训练损失 | 2021 未看过数据损失 |
|---|---|---|
| 考虑 1 天 | 480 | 580 |
| 考虑 7 天 | 380 | 490 |
| 考虑 28 天 | 330 | 460 |
| 考虑 56 天 | 320 | 460（不再降低）|

**线性模型**：$y = b + \sum w_j x_j$ 的形式。把特征乘权重加偏置。

---

## 4. 线性模型的局限与分段线性曲线

线性模型永远是直线，$x_1$ 越大 $y$ 越大。但现实中可能是「$x_1$ 小时成正比，$x_1$ 太大反而变少」——**模型偏差（Model Bias）**：来自模型的限制，无法模拟真实情况。

### 4.1 分段线性曲线 = 常数 + 一堆 Hard Sigmoid

**Hard Sigmoid**：先水平 → 斜坡 → 再水平的函数。

红色曲线 = 常数项 + 多个 Hard Sigmoid 叠加：
- 每段转折用一个 Hard Sigmoid
- 转折点越多，需要的蓝色函数越多

**任意连续曲线**：取足够多点 → 分段线性曲线 → 用 Hard Sigmoid 组合。**只要有足够的蓝色函数，可以逼近任何连续曲线。**

### 4.2 用 Sigmoid 逼近 Hard Sigmoid

$$y = c \cdot \frac{1}{1 + e^{-(b + wx_1)}} = c \cdot \sigma(b + wx_1)$$

- $x_1 \to +\infty$：$e^{-(b+wx_1)} \to 0$，$y \to c$
- $x_1 \to -\infty$：分母 $\to \infty$，$y \to 0$

调整 $b, w, c$ 可以制造不同形状的 Sigmoid：
- 改 $w$ → 改斜率
- 改 $b$ → 左右移动
- 改 $c$ → 改高度

### 4.3 多特征 + 多 Sigmoid 的统一形式

$$y = b + \sum_i c_i \cdot \sigma\left(b_i + \sum_j w_{ij} \cdot x_j\right)$$

用矩阵表示：

$$\mathbf{r} = \mathbf{b} + \mathbf{W}\mathbf{x}, \quad \mathbf{a} = \sigma(\mathbf{r}), \quad y = b + \mathbf{c}^T \mathbf{a}$$

- $\mathbf{x}$：特征向量
- $\mathbf{W}, \mathbf{b}, \mathbf{c}^T, b$：未知参数
- 把所有参数拉直拼成长向量 $\boldsymbol{\theta}$，损失变成 $L(\boldsymbol{\theta})$

> ❓ Q：Sigmoid 个数能多能少吗？
> A：自己决定（超参数）。越多能逼近越复杂的函数。

## 5. 梯度下降（批量版）

参数变多后用 $\boldsymbol{\theta}$ 统称，更新公式：

$$\mathbf{g} = \nabla L(\boldsymbol{\theta}^0), \quad \boldsymbol{\theta}^1 \leftarrow \boldsymbol{\theta}^0 - \eta \cdot \mathbf{g}$$

$\mathbf{g}$ 叫**梯度（gradient）**，是各参数偏导数组成的向量。

### 批量（Batch）

实际操作时把 $N$ 笔数据随机分成一组组批量（batch），每个批量 $B$ 笔：
- 用一个 batch 算 $L^1$ → 算梯度 → 更新参数
- 换下一个 batch 算 $L^2$ → 更新
- ……

| 术语 | 含义 |
|---|---|
| **更新（update）** | 每用一次 batch 算梯度更新参数叫一次更新 |
| **回合（epoch）** | 把所有 batch 都看过一遍叫一个回合 |

例：10000 笔数据，batch size = 10 → 1000 个 batch → **一个 epoch 更新 1000 次参数**。
1000 笔数据，batch size = 100 → 10 个 batch → 一个 epoch 更新 10 次。

## 6. 模型变形：激活函数

### 6.1 ReLU

Hard Sigmoid 也可以用两个 **ReLU（Rectified Linear Unit）** 叠加：

$$\text{ReLU}(x) = c \cdot \max(0, b + wx_1)$$

- $b + wx_1 < 0$ → 输出 0
- $b + wx_1 > 0$ → 输出 $b + wx_1$

**2 个 ReLU = 1 个 Hard Sigmoid**，所以 $i$ 个 Sigmoid 等价于 $2i$ 个 ReLU。

### 6.2 Sigmoid / ReLU = 激活函数

通用名是**激活函数（activation function）**，Sigmoid 和 ReLU 最常见，实验中 ReLU 效果更好。

### 6.3 实验对比（考虑 56 天）

| 模型 | 训练损失 | 2021 数据损失 |
|---|---|---|
| 线性 | 320 | 460 |
| 10 个 ReLU | ~320 | ~460 |
| 100 个 ReLU | 280 | 略好 |
| 1000 个 ReLU | 更低 | 无变化 |

### 6.4 多层（深度）

把 $\mathbf{x} \to \mathbf{a}$ 的运算反复多做几次（$\mathbf{a} \to \mathbf{a}' \to \mathbf{a}'' \dots$），次数是超参数。

| 层数 | 训练损失 | 2021 数据损失 |
|---|---|---|
| 1 次 | 280 | — |
| 2 次 | 180 | — |
| 3 次 | 140 | 380 |
| 4 次 | 100 | 440 ← **过拟合** |

> **过拟合（Overfitting）**：训练损失更低但测试损失更高。选模型时**测试数据上的表现更重要**——选 3 层而非 4 层。

## 7. 深度学习

- **神经元（neuron）**：一个 Sigmoid / ReLU 单元
- **神经网络（neural network）**：很多神经元串起来
- **隐藏层（hidden layer）**：每一排叫一层
- **深度学习（Deep Learning）**：很多隐藏层叠起来

| 网络 | 年份 | 层数 | ImageNet 错误率 |
|---|---|---|---|
| AlexNet | 2012 | 8 | 16.4% |
| VGG | 2014 | 19 | 7.3% |
| GoogleNet | — | 22 | 6.7% |
| ResNet | — | 152 | 3.57% |

> 训练神经网络用**反向传播（BackPropagation, BP）**——更有效率的算梯度方法。

## 8. 机器学习框架总结

数据集：

$$\text{训练数据：}\{(x^1, y^1), (x^2, y^2), \dots, (x^N, y^N)\}$$
$$\text{测试数据：}\{x^{N+1}, x^{N+2}, \dots, x^{N+M}\}$$

训练 3 步骤：

1. **写函数**：$f_\boldsymbol{\theta}(\mathbf{x})$，$\boldsymbol{\theta}$ 是所有未知参数
2. **定义损失**：$L(\boldsymbol{\theta})$ 判断参数好坏
3. **优化**：$\boldsymbol{\theta}^* = \arg\min_\boldsymbol{\theta} L$

把 $\boldsymbol{\theta}^*$ 代入 $f_\boldsymbol{\theta}$，输入测试集 $\mathbf{x}$，输出预测结果。

## 10. 主成分分析（PCA）

> 来源：吴恩达 NLP 课程 1 · 第 3 周（`code/NLP_wuenda/lecture_one/third_week/`）
> 关联 QA：[[Q&A_PCA]]

### 10.1 一句话理解

**PCA 就是把坐标轴转一下，让数据在新方向上散得最开，方便人眼看。**

### 10.2 为什么需要旋转？——高维数据的可视化困境

词向量有 300 维，人眼只能看 2 维。直接从 300 个维度里挑 2 个画散点图？信息损失太大——你挑的两个维度不一定能反映数据的真实分布。

PCA 的做法：**不挑原始维度，而是把所有维度按权重融合成 2 个新维度**，让数据在这 2 个新方向上尽可能散开（方差最大）。这样画出来的散点图保留了最多的信息。

> 直觉：拍 3D 雕塑的照片，从正面拍能看到最多细节，从正上方拍可能只看到一个点。PCA 就是自动帮你找"最佳拍摄角度"。

### 10.3 旋转的具体过程

以 2 维数据为例（来源：`NLP_C1_W3_lecture_nb_03.ipynb`）：

1. 数据散布在一条斜线上（两个特征高度相关）
2. PCA 找到数据散布最大的方向 → **PC1（第一主成分）**
3. 再找到垂直于 PC1、方差第二大的方向 → **PC2（第二主成分）**
4. 把坐标系旋转到 PC1/PC2 方向 → 数据在新坐标系下不再相关

旋转矩阵（以 45° 为例）：

$$R = \begin{bmatrix} \cos\theta & \sin\theta \\ -\sin\theta & \cos\theta \end{bmatrix} = \begin{bmatrix} 0.7071 & 0.7071 \\ -0.7071 & 0.7071 \end{bmatrix}$$

PCA 找到的就是这个 $R$——让数据在新轴上方差最大的那个旋转角度。

**示例**：数据 `y = x`（完全相关），PCA 自动找到 45° 旋转，解释方差 `[0.1667, 0]`——PC1 占了全部方差，PC2 为 0（数据在一条线上，垂直方向没有分散）。

### 10.4 PC1 和 PC2 是什么？

**不是从原始特征里挑 2 个，而是把所有特征加权求和造出 2 个新数字：**

$$\text{PC1} = w_1 \cdot f_1 + w_2 \cdot f_2 + \dots + w_{300} \cdot f_{300}$$

$$\text{PC2} = v_1 \cdot f_1 + v_2 \cdot f_2 + \dots + v_{300} \cdot f_{300}$$

每个词都做这个计算：把 300 个数字按 PC1 的权重加起来得到 x 坐标，按 PC2 的权重加起来得到 y 坐标。这两个数就是它在散点图上的位置。

### 10.5 数学步骤

| 步骤 | 操作 | 代码 | 为什么 |
|---|---|---|---|
| 1. 中心化 | 减去均值 | `X - np.mean(X, axis=0)` | 让数据以原点为中心，消除平移影响 |
| 2. 协方差矩阵 | 算特征间的相关性 | `np.cov(X, rowvar=False)` | `rowvar=False`：每列是一个变量 |
| 3. 特征值分解 | 找方差最大的方向 | `np.linalg.eigh(cov_matrix)` | `eigh` 适用于对称矩阵，比 `eig` 快 |
| 4. 排序 | 特征值从大到小 | `np.argsort(eigen_vals)[::-1]` | 大特征值 = 方差大 = 信息多 |
| 5. 取前 K 个 | 保留信息最多的方向 | `eigen_vecs[:, :k]` | 每列是一个特征向量（新坐标轴） |
| 6. 投影 | 高维 → 低维 | `X_demeaned @ eigen_vecs_subset` | 矩阵乘法 = 旋转坐标 |

**特征值 = 方差**：特征值越大，说明这个方向上数据越散，信息越多。丢掉特征值小的方向，损失的信息最少。

### 10.6 从零实现 PCA（作业代码）

> 来源：`homework/C1_W3_Assignment.ipynb`

```python
def compute_pca(X, n_components=2):
    # 1. 去均值
    X_demeaned = X - np.mean(X, axis=0)
    
    # 2. 协方差矩阵
    covariance_matrix = np.cov(X_demeaned, rowvar=False)
    
    # 3. 特征值分解（eigh 适用于对称矩阵，比 eig 快）
    eigen_vals, eigen_vecs = np.linalg.eigh(covariance_matrix, UPLO='L')
    
    # 4. 降序排列
    idx_sorted_decreasing = np.argsort(eigen_vals)[::-1]
    eigen_vecs_sorted = eigen_vecs[:, idx_sorted_decreasing]
    
    # 5. 取前 K 个特征向量
    eigen_vecs_subset = eigen_vecs_sorted[:, :n_components]
    
    # 6. 投影到低维空间
    X_reduced = np.dot(eigen_vecs_subset.T, X_demeaned.T).T
    
    return X_reduced
```

### 10.8 PCA 的用途

| 用途 | 说明 |
|---|---|
| **可视化** | 300 维词向量 → 2 维散点图，看词与词的语义关系 |
| **降维加速** | 高维数据 → 低维，减少计算量和内存 |
| **去噪** | 方差小的方向往往是噪声，丢掉反而更干净 |

### 10.9 关键概念

| 概念 | 一句话 |
|---|---|
| PC1 | 方差最大的方向，携带最多信息 |
| PC2 | 垂直于 PC1，方差第二大 |
| 特征值 | 每个主成分方向的方差大小 |
| 特征向量 | 旋转矩阵的每一列，即新坐标轴方向 |
| 解释方差比 | 各主成分方差占总方差的比例 |
| 中心化 | 减均值，让数据以原点为中心 |

## 11. 个人理解 / 待探索

- 线性模型 → Sigmoid/ReLU 组合 → 分段线性曲线 → 逼近任意函数，这条路是神经网络能学到复杂关系的核心思路
- 「局部最小值是假问题」这句话印象深刻，要继续看后续章节讲真正的难题是什么
- batch size 和 epoch 的关系容易搞混：epoch = 全数据扫一遍，更新次数 = N/B
- 过拟合的判断标准是**测试损失**，不是训练损失——选模型要选泛化能力强的
- PCA 的本质是**旋转坐标系**——不是从原始特征里挑 2 个，而是把所有特征按权重融合成新的方向。方差最大的方向（PC1）保留最多信息，方差小的可以丢掉实现降维
- PCA 主要用途是**可视化**：把几百维的词向量压到 2 维画散点图，就能直观看到词与词的语义关系（猫和狗靠近，汽车和飞机靠近）
- 从零手写 PCA 让我真正理解了每一步：中心化 → 协方差矩阵 → 特征值分解 → 排序 → 投影。核心就是找到让数据方差最大的旋转角度
- PCA 与后续课程的关联：[[自注意力机制]]里的 Q·K 点积、[[Transformer]]里的注意力计算，和本周学的向量运算、相似度都是同一套线性代数基础
