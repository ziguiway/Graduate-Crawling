## 五、我的理解

老师一次给 16 篇全是 IPM（JCR Q1 顶刊），意味着这个方向是**当前主流且被审稿人认可的**。从分类看：

1. **多模态是绝对主流**（9/16）— 假新闻现在不只是文本，图文配合造假才是真问题
2. **LLM 增强是近 1-2 年的新趋势**（6 篇，几乎都是 2024-2025）— 老方法嫁接 LLM 能力是新发文章的套路
3. **传播图+评论语义**是另一条线（5+2 篇）— 不看内容看传播路径，适合社交场景
4. **可解释性**（3 篇）— 审稿人越来越看重，不是只看准确率

**给自己的建议**：
- 先从 **#3 BCMF** 入门多模态基础（最老的，地基稳）
- 再看 **#11 LLM-assisted boosting** 或 **#12 LLM Multi-Task** 了解 LLM 增强套路
- 然后选一个自己感兴趣的方向深入（比如多模态+解耦 → #16，或传播图 → #5）
- 不要 16 篇全精读，**P1 的 4 篇精读 + P2 略读**就够建立认知地图了
