## 三、读论文路线建议

### P0 先建全局（综述类）
按“主流全景 → 方法分支”的顺序读：

1. **#17 Multimodal approaches survey (DKE 2026)** — 最新、最适合做总地图；用“特征提取-融合方法-学习目标”三轴框架串起多模态方法。
2. **#19 GNN methods survey (Applied Soft Computing 2023)** — 想理解传播图、异构图和图网络路线时读。
3. **#18 Explainable AI survey (EAAI 2023)** — 想深入可解释性时读，重点看解释类型与评估指标。

**#20 Machine intelligence approach** 不必放在 P0：它更像传统文本分类算法的快速回顾+小型实验，适合补基础时略读。

### P1 精读 4 篇代表作（覆盖主流派）
按"流派不同"选，避免重复：
1. **#3 BCMF (IPM 2022)** — 多模态基础流派，双向融合，老但经典，**入门多模态假新闻的最佳起点**
2. **#5 Collective propagation (LLM hypergraph, ~2024)** — 传播图+LLM 混合，近年趋势
3. **#11 LLM-assisted adaptive boosting (~2024)** — LLM 增强+集成学习，方法新且易迁移
4. **#16 Uncertainty-aware disentangled (IPM 2025)** — 概率表示+解耦，理论较新，2025 最新

### P2 略读（看摘要+框架图+结论）

## 五、我的理解

老师先给 16 篇 IPM 研究论文，现在又补 4 篇综述/回顾，意图很像是：**先从最新方法里看“大家在做什么”，再用综述把零散方法放回整体地图。**从原有 16 篇研究论文的分类看：

1. **多模态是绝对主流**（9/16）— 而且新增的 #17 专门用整篇综述这条路线，进一步说明它是当前主线
2. **LLM 增强是近 1-2 年的新趋势**（6 篇，几乎都是 2024-2025）— 老方法嫁接 LLM 能力是新发文章的套路
3. **传播图+评论语义**是另一条线（5+2 篇）— #19 可以补足图方法的理论地图
4. **可解释性**（3 篇）— #18 补了解释类型、解释对象与评估指标，说明这不只是“画个注意力图”

**给自己的建议**：
- 先读 **#17 多模态综述**，只需抓住三轴分类法、数据集表和 future work，先画出地图
- 再从 **#3 BCMF** 入门多模态基础（最老的，地基稳）
- 再看 **#11 LLM-assisted boosting** 或 **#12 LLM Multi-Task** 了解 LLM 增强套路
- 然后选一个自己感兴趣的方向深入（比如多模态+解耦 → #16，传播图 → #5/#19，可解释 → #18）
- 不要 20 篇全精读，**P0 先搭地图 + P1 的 4 篇精读 + P2 略读**就够了
- 想动手跑代码的话，只有 #11、#13、#15 有开源仓库（见总览表「代码开源」列）；P1 精读清单里只有 #11 有代码，精读时可以直接对照 [cgao-comp/FEND](https://github.com/cgao-comp/FEND) 复现，其余篇目只能照着论文自己推实现
