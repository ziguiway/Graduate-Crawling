## 二、三周阅读路线

### 第一周：只看 5 篇（入门门槛）
LLaVA(1) → Qwen2.5-VL(3) → FigStep(4) → VLGuard(8) → MM-SafetyBench(15)

读完必须能回答：
1. VLM 是怎么工作的？（图像怎么进入模型、Vision Encoder 干什么、特征怎么和 LLM 对齐）
2. 为什么视觉会成为新的攻击面？（为什么文本安全不能直接继承到视觉）
3. 什么是 multimodal jailbreak？
4. VLGuard 怎么防？
5. MM-SafetyBench 怎么测？

### 第二周：攻击—防御对抗（5 篇 + 建表）
Jailbreak in Pieces(5) → BAP(6) → AdaShield(10) → MLLM-Protector(9) → SPA-VL(11)

攻击→防御位置地图（这张表以后是选题地图）：

| 攻击 | 攻击位置 | 防御位置 |
|---|---|---|
| FigStep (4) | Visual（图内文字） | Prompt / Alignment |
| Jailbreak in Pieces (5) | 跨模态对齐过程 | Alignment |
| BAP (6) | Image + Text 联合 | Cross-modal 检测 |
| Visual Cipher / Object Replacement (7) | Vision（纯视觉推理） | Detection / Alignment |
| Adversarial Perturbation (6,13) | Vision embedding | Robust Training / 净化 |

### 第三周：最新防御（找创新点）
Attack as Defense(12) → SAFEMLLM(13) → ReCon(14)，然后回读综述 17→18→19→20。

防御四条路线（在哪防）：
1. **输入端**：Image → Purification → MLLM（AsD、ReCon 的净化器）
2. **Prompt 端**：Defense Prompt 包裹输入（AdaShield）
3. **模型端**：Adversarial Training / Safety Alignment（VLGuard、SPA-VL、SAFEMLLM）
4. **输出端**：Harm Detector → Detoxifier（MLLM-Protector、ReCon 的反转注入）

核心矛盾：**安全性 vs 可用性**。粗暴防御（见可疑全拒绝）ASR 低但正常图片也拒 → 模型没用。好防御 = 在攻击防御、正常能力、计算开销之间取平衡（MMJ-Bench 的评测思路正是如此）。

## 三、候选硕士论文方向（观察用，不急着定）

1. **跨模态 Jailbreak 检测**：单看图正常、单看文正常、组合起来恶意 → Cross-modal Detector + Risk Score
2. **Visual Prompt Injection 防御**：图中藏 "Ignore previous instruction..."，OCR 后被当指令 → Instruction Detector + 中和
3. **自适应多模态安全防御**：轻量检测打分 → 低风险走正常模型，高风险走净化+强防御 → 同时优化 Security / Utility / Latency
